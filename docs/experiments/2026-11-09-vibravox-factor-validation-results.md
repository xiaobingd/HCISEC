# VibraVox复核：哪些本地结论得到支持

九目标及8个唯一训练分组全部完成。现有speech_clean原始额头加速度缓存中按文本覆盖和固定哈希选择9人1040原始录音；不是按认证成绩选人。采集字段是实际单轴额头加速度，不是本地OpenVR三轴速度。

## 数据与协议

1040个ACC缓存载荷哈希全部核对，无完全重复；源说话人/句子/Parquet行映射已单独复核。572拟合、144开发、108注册、216查询，真实规范化文本全局不跨角色。每人12注册、24查询。选中子集的文本均只对应一个用户，所以只能称跨句身份隔离，不能报告同内容攻击或严格排除用户间文本分布差异。

每折4Base/2Cal/1目标/2未见攻击者；仅Base-fit尺度/PCA/训练，Base-develop选checkpoint，Cal相互攻击选阈值。目标与未见攻击者从未参与这些步骤。单seed42，第九目标与第一目标共享训练分组。原型余弦后端相同，所有目标都保留。每目标24本人/48未见攻击，九目标共216本人决策、432攻击决策。

主前端为50–7600Hz、1×40×28对数功率；2秒中心窗、256msHann/64ms hop，所有架构同源。真实传感器具有宽频响应，不硬套HMD的300Hz。另有10–300Hz和50–1200Hz原统计对照。四路线为原统计240维、Base-fit PCA192、MLP240→256→192、单通道ResNet18/192；神经网络从头200步、相同CE+0.1SupCon/AdamW1e-4批次16，不使用Audio或预训练教师。

## 对本地结论的支持边界

本轮支持程度具体如下：

- **支持平均频谱形状主线。** 删除该块AUC从0.97965降至0.91811；形状单独AUC0.99720。它说明当前额头信号存在强用户相关频谱差异，不等于已经排除佩戴或文本分布影响。
- **幅度不是必要信息，不能笼统“越保留越好”。** 去掉幅度块AUC提高至0.99103；形状单独在模拟均匀增益下指标完全不变。原统计增益后HTER明显变差而AUC较稳定，说明分数/阈值迁移也是重要问题。
- **支持本轮ResNet退化，但仅限少量Base从头训练。** 原统计AUC0.97319/HTER12.96%，ResNet0.89863/19.68%。即使额头物理加速度而非HMD速度也出现此排序，所以不能将原先全部退化归因于本地前端错误。
- **不支持“所有监督编码器都严重损伤”的泛化。** VibraVox统计MLP为0.96836/14.47%，与原统计较近，差异远小于本地MLP；单seed不足以判断这一小差距稳定性。PCA192为0.97309/13.08%，仍说明192维本身不是主要问题。
- ResNet在已知Base拟合/留句开发配对AUC约1.000/0.9966，但未见目标认证较弱，符合“学会分已知身份却未充分保持新身份距离结构”的解释。开发配对与最终原型认证并非同一个统计任务，不能直接把两AUC相减称严格泛化差。当前未通过增加Base或修改归一化/池化做因果检验。
- **不能验证本地采集日期或真实重戴的影响。** 公共数据缓存没有对应条件标签，不能证明本地原统计完全是生理身份，也不能证明其全部是伪影。

平均频谱形状的重要性复现：删除形状AUC下降；幅度不是必要身份线索，去掉幅度可提高排序。相对时间块单独较弱的现象也复现；波动块在VibraVox比本地更有可分性，不能将本地相对贡献比例直接推广。

均匀增益下，原统计操作点敏感、去幅度形状稳定，支持将幅度与形状分开。但没有重戴/跨设备采集标签，不能因此证明真实佩戴鲁棒。宽频与10–300Hz的差距说明需按传感器定频段。

本地的日期/采样条件混杂无法由本数据直接验证或否定，现有缓存没有相同的采集时间戳/重戴标签；真正的额头加速度数据复现某些统计规律也不能证明本地vVelocity的生理来源。所有结论是探索性数据集复核，不是盲测试或完整VibraVox benchmark。

官方VibraVox论文另使用预训练ECAPA2做说话人验证；那不是本轮四Base从头ResNet/MLP协议，不能将两者混为一谈。公开只保存代码、协议、聚合数据；原音频、逐身份/文本关系、阈值和逐目标结果保持私有。

本轮源数据来自官方speech_clean的train分片缓存，在所选用户内重新划分身份；不复用此前教师权重，目标对本轮模型是未见身份。这不是官方test划分的完整benchmark分数。所有1040个缓存索引的说话人、句子编号与规范化文本都已同原始Parquet元数据逐条核对，无冲突。
