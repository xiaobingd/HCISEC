# mei九人闭集：Audio辅助身份表征＋个人CycleGAN补充

本次是全新闭集对照，不把旧开放模型的all_eight_mixed攻击范围改名为闭集。九位用户都参与身份表征训练；每个用户独立二分类RBF认证头使用本人及其余八人的注册样本，所有八个攻击来源保留。

## 数据和划分

使用已去重并按时间戳配对的2695条九人共同前端记录。输入是三轴OpenVR tracking vVelocity频谱，不是原始硬件加速度；沿用10–300Hz、三轴各40频带及原始28时间格。所有人的处理规则相同，不按用户改变滤波。单人G/F微调后也不重新拟合个人归一化。

词序仍为先前推断的名义分组，尚未逐条核验转写；因此下文写“名义同词/跨词”，不能宣称严格语义核验完成。

| 角色 | 每人数据 | 用途 |
|---|---|---|
| fit | 名义词0–7、10–17的全部记录，160条 | 九人共享身份编码器与共享G/F预训练 |
| develop | 词8、9、18、19各第一条，4条 | 只选择共享G/F检查点 |
| registration | 词20–23各前3遍，12条 | 单人G/F微调、九个二分类头的训练 |
| CalA | 词20–23各第4遍，4条 | 分支选择过程中的阈值 |
| CalB | 词20–23各第5遍，4条 | 跨九目标选择分支/步数/权重 |
| sameword Test | 词20–23各第6–9遍，16条 | 独立录制的名义同词查询 |
| crossword Test | 词24–29各前4遍，24条 | 名义未见词查询 |

所有样本索引互斥。未使用的重复录制保留，不基于认证效果删除。名义同词每目标16本人/128攻击比较；跨词24本人/192攻击。每人Cal合并A/B共8本人/64攻击，用于最终阈值，查询标签不参与模型或阈值选择。

## 表征与教师

九人共同的ACC学生738→192残差编码器，先在fit身份监督CE＋0.1SupCon训练700步，同批使用相同名义词的不同用户。Audio教师从原始VoxCeleb ECAPA初始化，在九人的fit回放每人4条及注册每人12条共144条Audio上微调100步，主体LR1e-6、分类头1e-4、BN统计固定，CE＋0.1SupCon＋原始表征锚定。

随后冻结Audio教师，用相同144条配对信息给ACC学生蒸馏100步，身份CE＋SupCon＋初始ACC锚定＋梯度EMA平衡RKD，rho=0.3、EMA=0.9、lambda上限100。没有使用Cal或Test Audio模型前向；缓存归档可能整体解压波形，不能把这表述成从未物理读取查询Audio字节。

原始形状保持120维（三轴各40维），与192学生拼成312维基线；另保留原始720维统计和学生单支路对照。

## 个人CycleGAN

共享G接收三轴频谱输出Audio频谱，F反向1→3；统一时间插值到32格。Audio为50–7600Hz的40频带对数功率谱，不是可听波形。每轴/每模态归一化仅拟合九人fit，应用于所有人。共享训练4000次更新、batch16，LSGAN＋10配对L1＋10循环L1；由于3/1通道不同，省略恒等映射损失。按36条develop录制选择共享G/F及对应判别器。

九位注册者分别从共享模型独立重置，只使用自己的12条注册配对微调G/F100步、batch6、LR2e-5，保存25与100步；固定共享判别器，不使用其他用户样本参与个人生成器更新。同一个目标生成器处理该目标和全部攻击者。

候选为输入G编码256、循环G编码256、循环三轴频谱统计720。特征标准化只用共享模型对fit数据的输出，之后固定。每个候选固定0.5权重报告；自主选择可选择25/100步、权重0.25/0.5/1，也允许不补充。CalA定阈值、CalB按九目标平均HTER/AUC选一个全局配置，锁定后才提取最终查询的个人G/F特征。

## 认证后端与报告

每种特征分别训练九个balanced二分类RBF SVM，固定C=10、gamma=scale。训练仅用108条注册数据，禁止拼接后再次StandardScaler消除分支权重。最终每头用CalA+B确定Cal-EER和Cal-FAR5阈值，两种查询使用同一阈值。后端与此前开放集余弦不同，因此仅在本轮内部对照方法增益，不把跨实验变化归因于闭集本身。

完整报告九位用户、同词/跨词、全部方法及双工作点；公开匿名汇总和计数，不公开原始信号、源姓名映射、权重、样本分数及阈值。单种子、同一头显、无重戴/跨设备控制，仍为探索实验。
