- 日期：2026-09-23
- 分析范围：bo、user2–user9
- 依据：E1-A、E1-B 与既有数据隔离核查的脱敏聚合结果
- 状态：聚合分析已完成；远程样本质量补充审计因 SSH 握手超时暂未执行
- 原则：不读取、展示或提交原始用户数据

## 核心判断

当前结果能够支持以下命题：

> 在个体化 CycleGAN 与认证头体系下，不同用户的认证难度差异稳定存在，且不是单一 calibration seed 的偶然现象。

但当前结果还不能单独证明：

> 个体化 CycleGAN 本身显著优于共享 CycleGAN 或无模态转换基线。

原因是仍缺少完全同划分、同认证头容量下的共享模型与无 CycleGAN 对照实验。

## 难度分组

仅用于探索性分析，不作为删除标准：

- 容易或中等偏易：bo、user2、user6、user7、user9；
- 中等：user4、user5；
- 困难：user3、user8。

user5 不属于“不可区分”，而是阈值/风险偏好明显失衡：FAR 很低，FRR 较高。user9 的 EER 较低，但 FAR 偏高，也不应只看 EER。

## 是否可以剔除 user8 或 user3

当前不建议从正式主结果中剔除，原因：

1. 样本量与其他用户一致；
2. 已有核查未发现跨用户精确重复；
3. EER 在 5 个 seed 下稳定，说明困难性可重复；
4. 困难用户恰恰体现真实落地中的个体差异；
5. 仅按模型性能删除会造成事后选择偏差。

可以在以下两种场景暂时移出：

- 工程调试：先用 7 个较稳定用户验证新方法是否能正常工作；
- 敏感性分析：同时报告全 9 用户结果与过滤后结果，并明确过滤规则和影响。

## 合理的数据剔除标准

只有满足预先定义、与模型性能无关的数据质量条件时，才建议从主分析中剔除用户：

- 文件损坏或无法解析；
- 非有限值、严重缺失或近零方差样本超过预设比例；
- 用户标识、模态或会话标签错配；
- 大量重复样本或训练/测试重叠；
- 采集流程明显不同，无法与研究协议对齐；
- 有独立记录证明传感器故障或采集失败。

阈值示例应在检查数据前写入协议，并保持对所有用户一致。EER 高、FRR 高或属于高混淆用户不能单独作为删除理由。

## 对创新点 1 的影响

当前最稳妥的创新点表述是：

> 个体化跨模态认证框架能够在九用户数据上实现约 5.54% 的宏平均 EER，并揭示稳定的用户级难度与风险差异；系统必须报告用户级性能和 worst-user 风险。

尚不应表述为：

> 个体化 CycleGAN 已被证明优于共享模型。

要使“个体化 CycleGAN”本身站得住脚，需要同一数据划分和同一认证头条件下完成以下配对对照：

1. Personalized CycleGAN + authentication head（当前方案）；
2. Shared pooled CycleGAN + 相同 authentication head；
3. No CycleGAN / raw ACC + 相同 authentication head；
4. 可选：identity mapping 或随机冻结生成器控制。

所有方案应报告：

- 5-seed 用户级 EER、FAR、FRR、HTER、Balanced Accuracy；
- macro-average 与 worst-user；
- 配对置信区间或置换检验；
- user3、user8 等困难用户的改善幅度；
- 完整用户结果与按预注册质量标准过滤后的敏感性结果。

## 结论

user8 和 user3 应暂时标记为困难用户，而不是坏数据用户。正式结果继续保留 9 人；工程调试可并行使用 7 人子集，但必须明确标记为探索性结果。创新点 1 当前具有可行性与用户异质性证据，但仍需共享 CycleGAN 和无 CycleGAN 的严格对照，才能形成因果层面的创新结论。


## 训练测试隔离修正（2026-09-23）

后续核对发现，之前的 CycleGAN 和认证头训练使用过全量数据，之后才在同一批数据上划分评估集。虽然评估脚本内部的 train/validation/test 索引交集为 0，但这不能证明评估测试样本对已训练模型真正未见。

因此 E1-A 和 E1-B 的数值降级为训练集内探索性结果，不作为严格独立测试泛化结论。原始数值保留用于溯源，但不能与严格隔离重训结果直接比较。

严格重做协议已经确定：

1. 先固定外层训练集和独立留出集，并保存不可变样本清单；
2. CycleGAN、认证头和模型选择只读取外层训练集；
3. 独立留出集再划分注册集、阈值校准集和最终测试集；
4. 所有 global/personalized、shared/personalized 和 raw/CycleGAN 对照使用相同清单；
5. 训练完成后再次核对训练历史与最终测试清单的交集。
