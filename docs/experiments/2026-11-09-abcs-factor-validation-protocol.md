# ABCS：身份统计消融与统一前端编码器对照

## 目的与边界

复现 Mei9 / VibraVox 的统计因素、模拟增益敏感性，以及 raw / PCA / 统计 MLP / ResNet18 对照。本轮不是 CycleGAN 或 Audio 蒸馏训练，不与先前 ABCS 八人闭集 SVC / T3 的数值混为一谈。

当前只有不完整压缩包可用。依元数据选择八个具有共同文本的完整用户，共有125个共同转写；不根据认证效果选择用户。通道0暂按用户提出的 BC 假设处理，公开资料尚未独立确认通道索引。通道1作为独立统计对照，不与通道0融合，结果在确认前均按通道编号解释。

## 固定协议

- 共同转写按固定文本哈希排序，所有用户逐角色使用同一组实际文本，不以文件数字后缀代替文本。
- 每人60句 Base 拟合、15句 Base 开发、12句注册、13句 Cal 查询、24句最终查询；剩余1句不用。五组文本两两不重叠，共992条原始录制。
- 八折：4个 Base 身份、2个 Cal 身份、1个完全未见的目标身份、1个完全未见的攻击身份，轮换所有目标。标准化、PCA 和编码器仅拟合 Base-fit。
- Cal 两身份相互攻击，以13句查询选择 FAR / FRR 差最小的阈值；并列时较低 FAR 优先。目标身份仅用12句注册建立余弦原型，不调整阈值或模型。
- 最终本人和攻击者均说相同24句；注册与查询文本不同。因此这是内容匹配攻击下的跨文本注册认证，不能称为同一用户同词独立重复训练/测试。
- 主结果每目标24次本人、24次未见攻击；另报所有7来源的辅助结果，其中包含 Base / Cal，不能冒充全部未见攻击。

## 统一前端与消融

16 kHz 原波形逐通道去直流。主实验保留整句；4096点 Hann、1024步长、16384 FFT，插值到40个几何频率及16帧。只规范化时频表示长度，不拉伸原始波形、不补零。主频带50–7600 Hz；10–300 / 50–1200 Hz 作固定频带对照。另设1.25秒中心窗统计对照。共同文本不代表逐帧音素对齐。

统计240维：40维频谱均值、40维时间标准差、四段均值160维。消融将均值形状、时间标准差、去均值的分段变化、幅度统计分块；各块 Base 标准化并按维数开方缩放，拼接后 L2。全因素246维与原统计240维的构成和加权不同，不能当成同一个 baseline。

模拟查询增益0.5 / 2，只改查询，冻结注册与阈值；不模拟 ADC 截断、传感器噪声或真实重戴。去频谱均值形状的增益不变性是代数性质，不能当成实测佩戴鲁棒性。

PCA192仅拟合 Base；MLP为240→256→192，ResNet18输出192维。两种网络均从头训练，CE + 0.1 SupCon，AdamW 1e-4、weight decay 1e-4、200步、seed42、batch16。每批四个 Base 用户说相同四句；同人异句为正、异人同句为困难负。每50步用 Base-dev 同人异句/异人同句 AUC 选择检查点。不利用最终目标效果挑选模型。

## 限制与发布

单种子、小样本、每目标仅一个未见攻击来源；不代表完整 ABCS。无可靠跨设备、重戴或跨天标记，不能证明身份差异的生理来源。与 VibraVox 的窗口长度、内容结构、折数和攻击来源数不同，跨数据集仅比较趋势，不能直接比较绝对数值。

公开代码、协议及全队列宏平均；原始音频、派生样本特征、逐用户及逐攻击源分数、映射、阈值保持私有。私有特征上传服务器被自动审批阻止，本轮八折均在本地计算。
