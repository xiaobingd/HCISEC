# Audio关系可预测性：已知用户、未见词验证

本轮独立于创新点一V1和历史模型。所有九人保留，不按结果选人。

## 固定隔离

- 从随机权重训练纯ACC IdentityEncoder，仅词0–11；标准化也仅这12词。CE、AdamW3e-4、1400步最终检查点、seed42，不看词12–17选择模型。
- 关系预测器仅用词0–11的冻结ReDimNet2-B3 Audio关系作标签；词12–17为独立离线验证。词18–29不参与。验证Audio在预测锁定后使用。
- 4条注册、4条查询，两折互换后平均关系；训练和验证均固定每人每词前8条，整词隔离。词顺序是历史名义映射，尚非转写核验。

## 预先指定预测器

ACC余弦、ACC训练身份关系均值、Audio训练身份对固定均值（记忆基线）、同容量ACC自回归Ridge、Audio监督Ridge、剥离固定关系后的残差Ridge、去词类特征Ridge、仅训练词10/11指令词Ridge、留出身份对Audio监督、留出目标用户所有Audio关系监督。

Ridge固定alpha10；StandardScaler仅拟合允许的训练行；同词/跨词监督总权重相等。不搜索超参数，不根据验证选方法。输入14维：ACC当前相似度、ACC训练关系先验、残差、行/列负类均值及标准差、两端本人相似度、行/列中心化相似度、同词标记、两端数字/指令类别。不输入用户或词ID one-hot；输入关系统计仍可能隐式表征已知身份，因此必须设置固定身份记忆及留关系监督对照。

查询身份标签只用于离线汇总身份原型和审计，不是在线认证器。留目标监督只约束轻量关系预测器的Audio标签；ACC编码器仍训练全部九人，绝不称开放集。

主要Audio监督预测器是Audio_Ridge；99次训练Audio身份整节点置换、同容量ACC自回归、固定Audio身份对记忆均为对照。不得从多个对照中挑最佳者冒充预先确定的方法。

## 控制与统计

- 同词、跨词分别计算每任务困难负类Spearman与Top1重合率，再等权宏平均用户；另给跨词汇总身份排序和固定身份对内部的词任务残差相关。
- 全部大小5/7/9的用户组合重新拟合关系预测器，共126/36/1组合，不筛选有利组合。此控制改变预测器和候选池人数，不改变九人ACC主干训练；报告不同攻击数量对应的随机Top1期望。
- 留出身份对监督排除该无向身份对两个方向所有训练标签；留目标用户监督排除该用户作为任一端的所有Audio标签。
- 验证12–17全为指令词，训练0–11为10数字+2指令。因此报告去词类和仅训练指令词对照，不能假称语义类别完全平衡。
- 500次整验证词块bootstrap，共用所有方法相同抽样；跨词至少两个不同词。区间条件于这九人，不把词对或攻击边当作独立受试者。
- 不训练局部蒸馏器。先判断独立词关系是否保留、Audio监督是否超出ACC及身份记忆；不能将预测相关直接解释为蒸馏认证收益。
