# E1：九用户五随机种子重复认证验证

- 实验 ID：`e1-multiseed-validation-20260922`
- 日期：2026-09-22
- 状态：已完成
- 目的：验证逐用户认证结果对随机校准划分的稳定性
- 用户范围：bo、user2–user9
- 随机种子：42、0、1、2、3
- 模型关系：每个用户使用自己的 CycleGAN 和自己的认证头
- 数据原则：只在 AutoDL 远程实例按用户隔离读取；GitHub 只保存聚合指标和哈希

## 协议

1. 保持原有一对多认证评估脚本和模型绑定关系不变。
2. 保持测试集固定为 seed=42 的分层划分。
3. 对验证集使用 5 个随机种子进行校准划分。
4. 每个用户独立输出到远程文件存储盘目录；不覆盖旧实验。
5. 每次运行检查训练/验证/测试交集和跨用户样本哈希交集。

本轮使用已修正的认证数据加载器：bo 读取完整 `acc.npy`，不再读取 `acc2.npy`。因此各次运行的 bo 样本数为 300；user2–user9 样本数保持为 300、297、297、300、300、299、299、299。

## 初步解释

- 用户间的认证难度差异在 5 个随机种子下仍然存在：user8、user3 较难，bo、user7、user9 较容易。
- EER 的种子波动总体较小，说明用户排序不是由单一随机校准划分完全造成。
- user5 呈现低 FAR、高 FRR 的保守认证特征；user3、user8 的 FAR 与 FRR 都相对较高。
- bo 的结果仍然较好，但完整数据修正后应以本条目为准，不能继续使用此前误读 `acc2.npy` 的诊断结果。
- 该实验只证明固定测试划分下的随机校准稳定性，不能替代跨时间、跨会话或跨设备验证。
