# 最新方案实验一：P1 E0/E1/E2执行协议

完成状态：ECAPA与ERes2NetV2各24折均已完成。[完整结果](2026-11-08-p1-enrollment-results.md)。48折复核通过：E0完全复现原ACC指标；lambda=0时E2与E0完全一致；查询Audio特征在评分数据中不存在。

对应GitHub方案commit ec2ec9b1cf285c195b119d59777c879f4f17d2eb 的P1。此前蒸馏与残差结果不等于本实验：此前未用新用户注册Audio构造其模板。

复用24个严格外层Base-only ResNet18检查点及对应192维HMD缓存，不更新骨干。Audio分别使用现有VibraVox Audio ECAPA和ERes2NetV2冻结缓存，两个教师独立运行、分别报告；不使用包含本地九用户的微调教师。

八位用户每人轮流作为目标，环形下1人为未见攻击、再2人校准、剩余4人训练；3种子42/43/44。E0/E1/E2共享每折HMD主干、12条注册发声及固定HMD查询。每方法用独立Cal身份确定一个同词/跨词共享EER阈值，不读最终目标分数调参。

- E0：12条HMD均值单位模板。
- E1：同12条Audio单位均值，经192→128GELU→192L2映射，形成HMD空间模板。
- E2：融合E0与E1模板，lambda网格0/.1/.25/.5/.75/1，仅Base内部选择，0为合法回退。

映射用AdamW学习率1e-3、权衰减1e-4；预算500步，每50步验证。损失为跨模态同人异词正对、异人同词权重2困难负对的监督对比，加0.1正确配对余弦损失。先按内层E1平均AUC选择训练步数，再在该步按融合AUC选择lambda；并列时选更小lambda。随后用全部4位Base fit数据按锁定步数重训映射。

内层4次留一Base身份仅对映射器实施身份留出；固定骨干此前见过全部4位Base身份。因此这是映射器级模拟未见用户，不是完整内层编码器未见身份。内层支持集为留出Base用户的数字0–5各前2次（12条），查询为4位Base用户develop四词各前2次。所有内层选择不访问Cal/Target/Attacker。

外层同词/跨词沿用final六词，两个三词组轮换方向：注册每词前4次、查询每词后4次，共同取每词前8次，K=12，两方向本人查询24条、严格未见攻击24条、全部七来源168条。Audio仅为注册池192条提取特征，HMD查询不访问Audio，也不运行Audio教师；每折只构造Cal及目标的注册模板，不使用该折攻击者Audio。

审计：原manifest2697组，未发现队内/跨用户精确载荷重复；八人排除yue属于既有探索性人群选择。两条fit录制bo:160、bro:069仅有sorted-row回退配对，统一从映射训练排除；192条注册录制均为精确时间戳配对。词标签仍来自顺序推断，未逐条人工语义核验，因此结果属于现有标签下的探索性同词/跨词实验。精确时间戳配对不等于证明逐采样同步或生理耦合；本轮不作耦合结论。
