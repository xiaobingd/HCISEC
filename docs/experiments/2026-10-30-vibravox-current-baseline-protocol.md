# VibraVox当前基线迁移先导

数据为官方speech_clean前额加速度计和头戴麦克风。复用10月28日已经按相同原始前端重新训练到200轮的两位个人CycleGAN，未使用Mei或ESMB生成器作为同域模型。本轮不重训生成器，新增每位注册者一个真实跨模态身份教师，并应用当前完整772维、纯ACC统计、输入/循环编码对照及ACC/生成Audio分数补充。

注册者2BuQxDAGnW、95rDQfTOk7；未知攻击者R7Mh-VA0Gl、Rsw6ppioe6。每个注册者GAN训练30句、验证6句、认证训练10句、校准6句、最终8句；两个未知身份各24句仅用于最终。一个完整原句形成两个相邻0.8秒窗口，特征先按句平均，句子才是独立划分和评分单元。未知身份不拟合归一化、教师、分类器或阈值。

所有用户同一前端：16kHz、FFT512、hop160，ACC线性STFT dB与麦克风80Mel dB到80×80。PCM位深和浮点转换按原文件处理。归一化参考仅使用两位注册者的GAN TRAIN合并统计，各域一份参考应用全部人和角色，不按用户归一化。

已有完整772维定义为输入G浅层128、瓶颈均值/标准差512、有符号循环差分经G浅层128、差分统计4。不包含显式循环ACC640编码，所以后者单列对照。源生成器每位仅30句、60窗口，200轮对应600个满批更新，并非充分使用全部语料。

每位个人教师采用相同ACC/Audio编码器、二分类读出与两身份CE，用两位已知身份的GAN TRAIN真实配对数据训练600步；不同句同身份为对比正对，真实跨模态身份一致性权重.1。GAN VAL平均ACC/真实Audio AUC选教师，认证数据不参与教师更新或选择。这里每目标一个新教师，不是Mei九用户三教师家族的等量复刻。

认证RBF按整句5外折3内折，C=1/10/100、gamma=scale/0.1，使用当前HTER=(FAR+FRR)/2首要目标；校准也同时使用本人和已知负类，不设本人接受优先。补充权重0/.25/.5/1，允许零补充；ACC16组合、生成Audio16、联合64、固定ACC后加Audio4。所有路线锁定后才最终评分，未见攻击者结果不用于重新选路。

官方转写经既有清单核查没有完全相同文本跨角色，但不同身份不是共同文本，不能解释为同内容认证或完全内容无关。缓存人群及历史最终数据此前被探索，现阶段只有8条本人测试和48条未知攻击，不作显著性、总体安全或传感器优劣结论。专用前额振动传感器也不同于VR IMU。

官方来源：[VibraVox数据卡](https://huggingface.co/datasets/Cnam-LMSSC/vibravox/blob/main/README.md)。
