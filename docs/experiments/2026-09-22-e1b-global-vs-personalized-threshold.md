# E1-B：Global Threshold vs Personalized Threshold

- 实验 ID：`e1-b-global-vs-personalized-threshold-20260922`
- 日期：2026-09-22
- 状态：已完成
- 目的：比较统一全局阈值与逐用户个性化阈值
- 用户范围：bo、user2–user9
- 随机种子：42、0、1、2、3
- 测试集：固定使用 E1-A 的 seed=42 测试划分
- 模型参数：不更新；复用 E1-A 已生成的逐用户模型和特征
- 数据原则：只在 AutoDL 远程实例按用户隔离读取；GitHub 只保存聚合指标

## 阈值定义

对每个 seed：

- 个性化阈值：每个用户使用自己的校准 genuine/impostor 分数确定 `tau_u`；
- 全局阈值：汇总 9 个用户校准数据的 genuine/impostor 分数，确定一个共同的 `tau_g`；
- 两种阈值都只使用校准数据；
- 两种方法在完全相同的测试样本上比较 FAR、FRR、HTER 和 Balanced Accuracy。

`HTER = (FAR + FRR) / 2`

测试 ROC/DET EER 单独计算，不受部署阈值选择影响；本实验重点比较固定阈值下的实际认证行为。

## 宏平均结果

| 方法 | FAR | FRR | HTER | Balanced Accuracy | Accuracy |
|---|---:|---:|---:|---:|---:|
| Global Threshold | 5.292% | 5.605% | 5.449% | 94.551% | 94.673% |
| Personalized Threshold | 5.589% | 5.939% | 5.764% | 94.236% | 94.372% |

5 个 seed 的平均测试 ROC/DET EER 均为约 5.544%；该数值不用于区分两种部署阈值。

## Worst-user 结果

| 方法 | 最大 FAR | 最大 FRR | 最大 HTER | 最低 Balanced Accuracy |
|---|---:|---:|---:|---:|
| Global Threshold | 9.896% | 11.333% | 9.320% | 90.680% |
| Personalized Threshold | 8.685% | 11.667% | 9.069% | 90.931% |

## 解释

1. 当前协议下，个性化阈值没有改善宏平均结果。Global Threshold 的 HTER 低约 0.315 个百分点，Balanced Accuracy 高约 0.315 个百分点。
2. 个性化阈值略微改善 worst-user：最大 HTER 从 9.320% 降至 9.069%，最低 Balanced Accuracy 从 90.680% 提升至 90.931%。
3. 个性化阈值对 bo 和 user3、user8 有帮助，但对 user2、user4、user5、user6、user7、user9 有不同程度退化。
4. 因此当前证据不能支持“个性化阈值普遍优于全局阈值”；更准确的结论是：个性化阈值提供了控制用户间风险差异的可能性，但需要进一步优化校准目标。

## 方法学限制

本实验的全局阈值是将 9 个独立认证头产生的校准分数直接汇总得到的。虽然当前分数来自归一化嵌入的相似度，但不同用户认证头的分数分布可能存在校准差异。因此后续正式论文实验应增加：

- 分数校准或标准化后再比较全局阈值；
- 固定目标 FAR 或固定目标 FRR 的阈值策略；
- bootstrap 置信区间和配对统计检验；
- 跨时间/跨会话测试；
- 用户级风险约束，例如最小化 worst-user HTER。

## 结论

E1-B 已完成，但当前结果不支持立即进入 E2。下一步应先进行分数校准、固定 FAR/FRR operating point 和统计置信区间分析，再判断个性化策略是否真正改善 worst-user 风险。
