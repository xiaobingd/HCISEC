## 解释与限制

本轮部分复现了 Mei9 / VibraVox 的趋势：

- 频谱形状有价值：全因素 AUC 0.9434，移除形状后为0.8861；仅形状0.9785，幅度单独0.7745。去除幅度后全因素 AUC 升至0.9586。不能据此认定生理来源或排除接触条件。
- 单纯压缩维数没有解决问题：原统计与 PCA192 的 AUC 为0.9329 / 0.9325；HTER同为39.58%。
- 当前从头训练的 MLP / ResNet 没有超过原统计：AUC 0.9078 / 0.7033。不过只有4个 Base 身份、200步，不能推广为深度方法普遍无效。
- Base-fit / Base-dev 身份配对 AUC：MLP 1.0000 / 0.9921，ResNet 1.0000 / 0.9610。开发集仍是 Base 身份，不能当作未见身份泛化证明。
- 形状仅用方案虽有0.9785的排序 AUC，FAR仍22.92%、TAR77.08%。因此独立 Cal 到未见用户的阈值泛化尚未解决。
- 原统计查询增益翻倍后 HTER 从39.58%升到46.09%；形状仅用的两个增益对照保持22.92%。这只是合成增益压力测试，不能代表重戴实验。

跨数据集比较只能看趋势：VibraVox 原统计 / 形状仅用 AUC 为0.9732 / 0.9972，ResNet为0.8986。ABCS使用整句、共同文本和一个未见攻击者；VibraVox使用固定2秒、非共同文本和两个未见攻击者，两者绝对数值不作直接方法优劣对照。

频谱形状消融、网络对照必须分别解释。AUC 只衡量排序，不能替代独立阈值下的 FAR / TAR。只有四个 Base 用户，200步、单种子；本轮不能证明深度网络普遍不如统计特征。

通道1为独立控制，不能据其数值推断通道语义。没有可靠重戴、设备或跨天标注，也未测量个体组织传递函数，因此不能把可分性直接归因于生物特征。没有同人同句的独立重复采集，不能冒称完整同内容/跨内容单变量对照。

整句时频表示统一16帧，无原波形拉伸或零填充；中心1.25秒仅作统计控制。125共同文本中124句参与实验，五用途文本分离，992条录制通过 CRC / 精确重复检查。
