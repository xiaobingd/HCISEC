# 注册条件下的个体化阈值：执行协议

使用现有P1冻结模型，固定E0、E2模板，分别比较 fixed、adaptive、adaptive_guarded，隔离模板变化与校准策略变化。两种Audio模型、8目标、3种子，共各24折。不是使用目标测试标签寻找个人最佳阈值。

g仅在4位Base身份的模拟注册任务上训练。每位24个任务，每任务12条注册（3词×4次）及Base独立develop HMD查询。为模拟未见注册身份，该任务的Audio→HMD映射只在另外3位Base训练；HMD编码器仍曾见过4位Base，与P1/E3相同限制。

输入为6维Audio/HMD注册一致性及3维模板相对背景身份的分数统计（中位、90分位、最大值）。这是对注册原型和质量的低维表示，不把384维原型直接交给小数据高容量网络。标签是该Base任务的EER阈值；StandardScaler+Ridge(alpha20)，配置固定。

外层背景为4个Base用户fit HMD身份中心，仅训练数据构建。内层留一时只有另3个Base中心，背景数量差异也是迁移限制，Cal不能保证完全纠正。不能凭这几个身份中心可靠估计未知攻击尾部。

将个人预测相对Cal注册预测中位数的差值限制在±0.1，再用eta收缩后加到原Cal全局阈值。候选eta=0/.25/.5/1，Cal以HTER最小且Cal FAR不高于fixed为约束选择；eta0为合法退回全局阈值。adaptive_guarded另允许背景最大相似度+Base学习的非负小间隔作为阈值下界，Cal在带/不带下界候选中选择策略。Cal FAR约束不是未见攻击者的安全保证。

目标个人阈值只依赖其合法注册Audio/HMD、训练背景和锁定的Cal策略，不访问目标本人查询或攻击查询标签。验证只读HMD查询、固定模板及阈值。同词/跨词共享生成器、Cal基准阈值、收缩和下界策略，但因注册词不同，生成的阈值数值可以不同；不得称为旧协议中相同数值阈值的单变量对照。

fixed分支逐折复现P1的TAR/FAR/HTER。所有分支原始余弦AUC应相同，因模板与查询不变；个人阈值后的margin AUC另列，不能解释成身份表征增加信息。报告全部用户、种子、两类攻击来源以及回退策略，不挑测试表现最好的策略。

输入标签仍依赖录制顺序、未逐条语义核验；八人群体此前排除yue属探索性选择。只有4位Base、2位Cal，方法是探索性验证。代码：experiments/identity_kd/run_enrollment_threshold.py。
