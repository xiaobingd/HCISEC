# Mei9：每位用户可能从Audio补充什么

本诊断只用已有144条训练/注册记录的冻结ECAPA目标与738维标准化ACC统计。正对为同人异词，负对为异人同词；对每个用户计算正负样本对相似度的AUC。它是训练内关系诊断，不是认证AUC，也不是独立泛化证据。Audio教师已在这些合法记录上微调，因此其训练表现可能偏乐观。词标签仍按采集顺序推断。

|用户|ACC关系AUC|Audio关系AUC|当前可提出的补充假设|
|---|---:|---:|---|
|U1|0.826|0.753|Audio训练关系较弱；优先保留ACC，暂无整体身份关系补充依据|
|U2|0.922|0.956|ACC已较强；Audio可能提供小幅身份关系校正，需验证增量|
|U3|0.756|0.827|可能补充跨词稳定身份关系；个人校准选择过Audio，但尚未证实测试增益|

|U5|0.669|0.783|Audio有较强训练身份排序，但此前蒸馏受损；关键是可迁移性而非加强蒸馏|

当前只能回答“哪类身份关系可能值得迁移”，不能从ECAPA192维直接断言某人应补F0、谐波、声道或发声节奏。下一步应逐人提取并验证F0/浊音周期性、共享频带谱、能量包络三个目标：先按词留出检查其能否由ACC预测，再检查其是否跨词稳定且区分身份，最后与同预算身份分支比较。候选资格必须同时满足可预测、跨词稳定、身份区分，选择仅用训练/校准记录，最终查询不参与。

这份分析不能据此挑选最终测试用户或删除攻击来源。最近个人化关系实验仍未超过原始ACC，不能把本表当作收益证明。完整训练内关系指标见outputs/mei_personal_audio_guidance_20261114/train_information_diagnostic_public.json。
