# 九人原始身份线索与深度编码器：统一前端受控实验

## 数据与可识别性边界

用户确认九人使用同一台头显，不存在同人重戴、跨天或换设备的独立重复采集。采集代码实际读取OpenVR vVelocity，不能称为原始IMU加速度或直接测得的骨传导波形。现有2695条精确时间戳配对记录只使用HMD三轴，不引入Audio，以隔离信息来源。

源数组重新逐条核对清单哈希，原始信号前端统一为：时间戳排序/去重复、1000Hz插值至2秒、逐轴去直流、256样本Hann窗/64hop/1024FFT，对数功率插值到10–300Hz的40个几何频点，共3×40×28。不做图像大小插值，不按用户滤波。取相同原始记录、相同时间窗和频点；原始统计、PCA、MLP、ResNet18均从这份前端生成。

源文件显示九人各一个采集日期，共五个日期；日期不等于佩戴或设备标签。用户与日期的设计矩阵存在共线性，不能将每个人的稳定差异进一步拆成生理因素或当天/佩戴因素。同一台硬件排除了不同头显个体差异，但没有排除个人佩戴松紧、位置、姿态或记录批次。

## 第一组：统计分量消融

原720维每轴由40频点的全局均值、时间标准差、四段均值组成。四段均值已经包含全局均值，简单删除第一块属于信息泄漏式消融。本轮先分解为：

- 平均频谱形状：全局均值减去该轴的跨频平均水平，3×40=120维。
- 波动：每频点的时间标准差，120维。
- 相对时间结构：四段均值各减该频点全局均值，480维。
- 幅度：三轴频谱整体水平3维，加原去直流波形的逐轴log RMS、peak、绝对值p50/p90/p99共15维，总18维。

四块共738维并非原720维的等距改写：加入了真实波形幅度统计，并且各块经Base-fit列标准化后除sqrt(块维数)，避免480维时间块仅凭维数占主导。因此全分块方案与旧原720维的差异不能单独归因于某个新分量。各删一块、四块单独、原720维和原720维去每轴水平全部保留报告。

增加采集条件代理对照：仅采样数量/时间间隔/端点/重复时间戳7维；仅向量更新比例和更新率2维；两者合并9维。向量更新统计可能受真实运动影响，不能将其当作完全独立于信号的设备标签。日期不作为认证特征。

模拟敏感性测试只改变最终查询：全轴增益×0.5、×2，以及XY轴交换。训练、注册、Cal与阈值保持原始状态；本人和攻击者查询都施加同一变换。增益对应约±6dB幅值变化，轴交换只是坐标扰动；它们不是实际重戴/换设备实验，不能替代独立采集。

描述性双因素线性方差分析分别以用户、推断词编号、二者组合解释每块变异。分析可使用全记录作为描述，但不参与任何认证拟合、阈值或checkpoint选择。尤其“用户解释比例”包含全部与用户共变的佩戴/批次条件，不等于生理身份贡献比例。

## 第二组：共同前端下的四条路线

1. 原始统计720维，固定变换，无身份监督训练。
2. Base-fit PCA192维统计，固定降维，检查仅维数压缩的影响。
3. 统计MLP：720→256→192，GELU，输出L2归一化。
4. 标准ResNet18：[2,2,2,2] BasicBlock，3轴作为3通道，直接输入40×28，输出192维L2归一化。从头初始化，没有沿用不同80×80前端旧权重。

Torch-only ResNet18的state_dict与forward已在服务器同torchvision ResNet18逐一验证一致，避免本地缺少torchvision而换成其他网络。MLP与ResNet参数量不同，不能将比较表述为同容量深度消融。

公共前端只用Base-fit逐轴总体均值/标准差归一化，不按录音归一化。统计720维进一步使用Base-fit列标准化，原始/PCA/MLP共享这份统计输入。ResNet接受同一前端的时频张量。两神经网络同batch、同seed42、同200次更新、同AdamW1e-4/weight_decay1e-4、同CE+0.1SupCon；每批4Base中各取2词×2条=16条。每50步仅Base develop的“同人异词/异人同词”配对AUC选择模型。200步是匹配预算探索，不证明已分别调到各网络最优。

额外线性读出探针固定Ridge alpha10，只用Base-fit从各路线表示预测四种统计分量，在最终目标查询上报告R²。探针测试标签不反向参与模型选择。负R²表示对目标的迁移还不如该目标真实分量均值参考；不能据线性探针失败断言表示中完全没有非线性信息。

## 共同身份划分与认证

沿用本日九人开放集协议：4Base、2Cal、1未见目标、2未见攻击者。八个原目标的环形分组固定，第九目标复用第一折Base/Cal分组；每折重新训练本轮统一前端模型。所有九人作为目标，不删yue。第九目标与第一目标共享同一训练分组的模型，九折并非九个独立训练。

只有Base fit训练与尺度拟合、Base develop选模。目标/两未见攻击者不参加通用训练、开发、尺度、PCA或Cal。每个目标12-shot单位均值模板＋余弦，两个方向24本人/48未见攻击；另单报含已见身份的全部八来源。Cal仅两身份相互攻击，合并同词/跨词与方向选固定共享阈值。查询保持一致，同词/跨词只换注册词组。词标签仍是录制顺序假设，没有完成独立语义核验。

为缩短等待，不同owner折在本地与服务器独立执行；同一折四路线的训练/尺度/认证都在同一环境。环境版本差异按折保留，不将跨环境微小差异视为方法效应。最终合并全部九目标，公开宏平均，不公开原始录音、身份映射、阈值、逐用户成绩及哈希。
