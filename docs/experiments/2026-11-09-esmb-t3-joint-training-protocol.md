# T3联合训练：共享频谱+发声包络辅助BC身份编码器

2026-11-09，用户明确要求启动T3。使用ESMB；不声称VR硬件ACC结果。

固定身份：4Base(0005/0006/0007/0021)、4Cal(0022/0023/0026/0027)、两个未见注册目标0024/0025。目标及Cal不参与编码器、教师目标尺度、输入尺度训练。Base前80窗/人拟合、80–99窗开发；每窗2秒，每3秒一窗。未见目标只用前120窗BC注册，最后40窗查询；Cal同样120/40注册和查询确定阈值。

T3目标L=CE身份分类+0.1SupCon+0.1共享谱MSE+0.1包络MSE。Audio仅提供Base拟合/开发监督，Cal和目标的Audio不读取。沿用Base诊断选定17个候选频带（中心约74–940Hz）的相对对数功率及logRMS包络，80时间点，各通道均值/标准差只由Base拟合窗估计。

BC新前端：64ms窗、16ms步长，50–1200Hz对数频率网格80行、80时间点，统一Base拟合1/99百分位尺度，所有用户相同。50–1200Hz是此次候选前端范围，不是已证明硬件带宽。新T0必须使用同一前端重训，不用旧0–8kHz压缩80行模型冒充匹配对照。

架构保留ResNet18及192维L2身份输出，从头相同初始化训练；预测头接layer1的64×20时序特征，卷积后插值至18×80。身份、共享谱和包络损失共同回传BC编码器；所有编码器参数参与优化。首次更新显式检查辅助损失到conv1的非零梯度。不使用冻结192维向量+离线回归替代联合训练。

四组顺序执行：T3真实配对、T0匹配无Audio、T3同人错时（80帧循环移位14帧）、T3异人错配（下一Base用户同窗口索引）。错配仅改变Audio辅助目标，不改变BC输入或身份标签。均seed42、批8（4人各2窗）、AdamW1e-4/weight_decay1e-4、200更新、相同初始化和采样计划。每50步按Base开发身份配对AUC选checkpoint，不以物理重建或最终测试选择。该AUC中的组是时间块，不是已核实词。

认证主比较固定为BC-only120条平均注册原型+余弦。4Cal互相攻击选择Cal-EER和Cal-FAR≤5%两个预定阈值规则；目标0024/0025相互攻击，另报全部9来源。每目标40本人/40未见攻击查询。最终Audio不输入教师或后端。

服务器无GPU、CPU配额约半核、2GB内存，单模型顺序训练，先实际启动T3；按实际step/status区分已运行和排队。已有独立任务保持运行，必要时根据内存实测调整执行位置，不改变实验损失/数据预算。单seed及此前已观察的目标属于探索性试验；本轮未训练T1/ECAPA或T2/F0对照。
