# 九用户身份认证规律分析

- 实验批次：`cyclegan-auth-validation-20260922`
- 分析对象：bo、user2–user9
- 数据原则：仅使用远程生成的聚合指标、计数和误接受统计，不读取或提交原始用户数据

## 结论摘要

当前结果支持继续推进以下研究假设：

> 用户间存在稳定的认证难度差异，因此为每个用户保留独立的 CycleGAN 模态转换模型、独立认证头和个性化阈值，比单一共享模型更合理。

但当前只有 9 个用户、一个固定划分和一个主要随机种子，结果应视为研究信号，不应直接视为最终部署结论。

## 观察到的规律

### 1. 用户差异明显，且不由样本量简单解释

除 bo 外，user2–user9 的测试真样本数均为 59–60，几乎相同，但 EER 从 0.0667 到 0.2336，平衡准确率从 0.8098 到 0.9149。

这说明性能差异更可能来自用户自身的信号可分性、模态转换难度、会话/动作差异或噪声，而不是训练样本数量。

bo 的样本量较小且表现显著更好，因此 bo 的优势不能简单外推到其他用户。

### 2. 不同用户的 FAR/FRR 权衡不同

- user5 的 FAR 很低，但 FRR 相对较高，表现为保守认证。
- user9 的 FAR、FRR 都较低，整体最均衡。
- user4 的 FRR 较低，但 FAR 仍有一定水平。
- user8 的 FAR 和 FRR 都偏高，是当前最困难的用户。

因此统一阈值不适合作为最终方案，个性化阈值校准具有研究价值。

### 3. 存在非对称的跨用户误接受关系

聚合误接受统计中出现了若干较高的方向性关系：

- user4 的认证器对 bo 的误接受比例较高；
- user2 对 bo 也出现较高误接受；
- user3 与 user5、user6 与 user8、user4 与 user7 之间存在较明显的方向性混淆信号。

这些关系更像是用户间的模态/特征相似性或会话条件相似性，而不是简单的随机误差。它们可以支持后续研究用户相似性图、难负样本挖掘和针对性对比学习。

由于 bo 的测试冒认样本数量较少，上述涉及 bo 的比例需要更大测试集复核。

### 4. user2 与 user3 的相同指标不代表数据重复

已完成独立核查：

- 原始文件哈希不同；
- 数据形状和样本数量不同；
- 逐样本精确哈希交集为 0；
- CycleGAN 与认证头哈希均不同；
- 验证特征哈希不同，逐元素相同占比为 0；
- 认证分数向量不同。

因此相同的 EER/FAR/FRR/平衡准确率来自固定测试划分下最终分类计数恰好一致，不能据此判断数据重复。

## 是否支持研究继续

支持，但支持的是以下较具体的研究命题：

1. 个体化模型确实有必要：用户间性能差异明显。
2. 个性化阈值确实有必要：不同用户的 FAR/FRR 权衡不同。
3. 需要研究用户间相似性：误接受关系具有方向性。
4. 需要报告用户级指标：宏平均不能替代逐用户结果。
5. 需要区分“数据隔离正确”和“认证性能高”：二者是不同验证维度。

当前结果还不能证明：

- 跨时间泛化已经成立；
- 跨设备泛化已经成立；
- 单次固定划分的指标具有统计显著性；
- user2/user3 的相同指标会在其他划分中持续出现。

## 建议的下一步验证

1. 对九个用户使用至少 5 个随机种子重复评估；
2. 增加按时间或会话划分的测试集；
3. 为每个用户单独校准阈值并报告置信区间；
4. 输出完整的用户×用户误接受矩阵；
5. 对高混淆用户对执行难负样本分析；
6. 对 user8 优先检查数据质量、会话差异和模态转换稳定性；
7. 仅在多次重复结果稳定后，再形成最终研究结论。
