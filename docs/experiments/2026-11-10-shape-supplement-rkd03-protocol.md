# RKD-03：保留40维频谱形状，只补充V4学生特征

用户要求仅运行“注册Audio微调ECAPA＋梯度平衡”路线。复用RKD-02同一数据、K12、seed42、35 Base/12 Cal/12 Test、全部11攻击来源；不重训其他路线。

## 保留与补充

固定谱形状为246维统计中的前40维：Base-fit逐维标准化后L2归一化。记为`s(x)`。Audio辅助的振动学生V4输出L2归一化192维`z(x)`。直接拼接：

`e(x) = [s(x); alpha*z(x)] / sqrt(1+alpha²)`

得到232维。40维分支没有可学习参数、不映射到192维、不受蒸馏梯度修改；只作所有样本相同的范数缩放。学生仍从振动输入计算，查询不读取真实Audio。

注册原型为12条联合表示的平均后L2归一化；查询联合表示与原型计算余弦。不是重新学习一个融合投影头，也不是把40维替换成学生向量。

## 权重与数据隔离

只在Base内部29训练/3内Cal/3内Dev模拟注册选择正权重alpha：0.05/0.1/0.2/0.3/0.5/0.75/1。alpha0仅为不补充的参考，不参加正权重候选选择，确保这轮确实测试补充分支。选择HTER最小，依次按宏AUC、较小alpha打破并列。

内层重新训练29身份S1初始学生700步，使用已完成的6位内部注册者个人微调教师及其adapted目标，分别训练V4个人学生100步；rho固定为RKD-02由Base选出的0.3。原始ECAPA主体微调参数、回放、梯度平衡和注册Audio边界均不改变。

外层24个V4学生/个人教师全部复用，零额外训练。alpha锁定后才计算外层查询联合评分；最终阈值仍仅由12位Cal模拟认证确定。报告固定40维、既有V4学生单独参考和唯一新增的232维补充路线。不训练冻结教师/旧权重/其他蒸馏分组。

## 核查与报告

校验拼接前40维严格等于原40维乘统一常数，独立按两分支内积展开重算联合分数，直接pairwise AUC核查；确认每目标24本人/264攻击、Cal-FAR5规则、注册/查询文本隔离。报告AUC、TAR/FAR/HTER、最困难目标与身份级配对差值。不能因最终效果较差回退alpha或挑选用户。单种子探索，原始Audio、逐人分数、模型与阈值保持私有；仅公开代码和队列汇总。
