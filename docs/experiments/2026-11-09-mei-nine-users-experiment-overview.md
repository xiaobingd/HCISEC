# Mei等本地九人数据：同词、跨词与开放集实验总览

汇总日期：2026-11-09。本文汇总已完成、已归档的结果，不把不同协议的最好指标拼成一组。TAR为本人接受率，FAR为攻击误接受率，HTER=(1−TAR+FAR)/2。以下均为百分比。

## 一、数据和结论边界

存在两套来源：旧九用户数组（历史U1–U9），以及后来从原始多来源文件重建的九身份数据（bo、bro、jin、ke、mei、qi、qisis、xin、yue）。不在缺少映射证据时将旧U编号直接等同于新姓名。重建数据2697组配对记录：bo/bro/jin/mei/qi/xin/yue各300，ke298、qisis299。

前100条对应数字0–9，后200条对应20个VR指令。旧数组Audio周期审计支持10项/20项轮换；后续原始重建缓存使用自己的录制顺序词编号。尚未完成统一逐条语义核验，所以本文“同词/跨词”均以各run的词映射假设为条件，不能写成全文本人工确认。10月29日前使用错误统一row//10或row%30分组的旧结论不作为严格跨词证据。

同词=训练/注册与测试词集合重叠，但录制不重叠。跨词=对应阶段词集合不重叠。两者均不自动等于未见用户。重建HMD源通道实际是三轴速度，ACC是历史简称；所有用户沿用相同预处理。

## 二、旧九人个人CycleGAN完整baseline

### 同词：完整772维+RBF及自主补充

每目标其余八个身份均为已知训练负类。个人G/F冻结，15词每词不同重复划分：认证训练75条本人、校准30条、测试30条；每目标240条攻击测试。补充为原始ACC统计及既有ACC教师的训练折选路，并非最终测试选最好方法。完整772维包含输入浅层128、瓶颈均值/标准差512、循环有符号差分浅层128、差分统计4；不能称为只使用循环ACC。

|---|---:|---:|---:|---:|
|完整772维+RBF|75.19|32.69|28.75|77.53|
|纯ACC统计+RBF|66.67|25.19|29.26|77.36|

### 跨词：从头训练的个人CycleGAN+原trainb头

9个个人CycleGAN各200轮，9个完整772维SupCon/BCE认证头各100轮。生成训练120/12内容组、开发30/3组；认证训练50/5组、选模30/3组、校准20/2组，最终47–50/5组。八攻击身份均参与认证训练，属于已见身份闭集。校准参与checkpoint选择，不是完全独立事后校准。单seed42。

九人宏平均：TAR64.04%、FAR36.02%、HTER35.99%、AUC68.94%。

## 三、原始重建九人：ACC编码器与本地Audio教师辅助

这组九人均参与表征训练，属于已见身份认证。每人160条编码器训练、40条开发，另外20条训练RBF头、20条校准，最终58–60条本人查询，全部八个攻击来源保留。最终词与之前角色词按当前缓存映射隔离，属于跨词探索，不是未见用户开放集。

Audio教师由预训练ECAPA迁移至本地训练/开发录制微调后冻结。ACC组输出192维，主体微调仅更新layer4和fc、固定前层及BN统计，500步，seed42。Audio辅助增加身份关系蒸馏。所有组使用相同StandardScaler+balanced RBF认证后端。

## 五、当前可以汇报的结论

1. 本地HMD信号包含可用的身份差异，但可靠性强烈依赖用户；旧U1与重建bo/bro/jin等某些run较好，不代表全九人普遍可靠。
2. 已见用户实验好于未见用户实验是观察现象；协议和样本数不同，不能计算纯粹的“开放集损失”。严格未见攻击FAR仍约20%上下，尚未达到稳定实用认证。
3. 原始ACC身份表征是当前主要支撑。CycleGAN完整特征能认证不等于证明Audio循环增加了身份信息；Audio迁移、关系蒸馏、注册融合尚未显示稳定独立增益。
4. 跨内容是必要评价轴，但单纯划分跨词不是算法创新。词语映射需完成原始清单/逐条语义核验，再用相同查询、身份角色、预算和阈值做匹配同词/跨词对照。
5. 当前不能报告“九人开放集120条注册同词与跨词都完成”；准确状态是：历史九人同词/跨词已归档、原始重建九人已见身份跨词已完成、后续八人严格开放同词/跨词和120条跨词已完成。
