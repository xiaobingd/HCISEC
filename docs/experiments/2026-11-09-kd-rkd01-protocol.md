# KD-RKD-01：Audio 关系知识蒸馏辅助振动身份认证

按用户提供的方案依次开展 P0/P1 → S0/S1/S2/S3 → 高阶及负控制 → ABCS → HMD。以下是首轮预先固定细节，执行状态见文末。

## 已锁定的数据与边界

现有 VibraVox 缓存12472条、84身份，59身份满足固定文本角色下的最低完整性条件。按 `sha256('KD-RKD-01-identity-v1|'+speaker)` 排序：35 Base、12 Cal、12 Test；不依据效果挑人。每人最多64 fit、16 develop、12 registration、24 query，共6783条。同人同文本去重；全局文本角色通过固定哈希确定，注册与查询文本互斥。不同用户并非说同一组句子，不冒充同词控制。

仅 Base-fit/develop 读取真实 Audio。使用未经本地适配的外部 VoxCeleb ECAPA，校验官方五文件哈希，全程冻结；禁止载入旧 VibraVox 微调教师或目标专属生成器。来源训练集为 VoxCeleb，不声称已进行跨语料真人身份的生物核验。Cal/Test 仅提取振动，教师数组相应行全零。

第一轮使用纯统计版，不加入没有严格 Base-only 来源证明的 CycleGAN。S0明确标为统计版，不写成“统计+CycleGAN”。

## 前端与教师门槛

每条原始同步配对录制取相同中心2秒，16kHz、去直流，保留绝对幅度；不按人选择滤波器。振动：STFT4096点Hann、1024步长、16384FFT，50–7600Hz的40个几何频率。246维包括平均谱形状40、时间标准差40、去均值四段变化160、谱均值及波形幅度统计6。所有可拟合标准化仅用对应训练身份 fit。

P1仅在 Base-develop 计算教师同人异句/异人关系、验证 AUC/EER及身份原型关系 Spearman。异人同句不足则报告样本数，不补造配对。预先固定启动门槛：Base-dev 教师 pair AUC >0.8；达不到则不继续将该教师用于正式蒸馏。

## 学生与开发

轻量246→192投影、192→64→192残差、L2输出；所有学生保留同容量192→192的蒸馏投影头。身份损失CE+0.1SupCon；32条身份均衡batch，8人×4个不同文本；AdamW1e-4、weight decay1e-4、最多1000步、100步检查；seed42/43/44。RKD非自距离按batch平均非零距离归一化，按同人异句/异人关系分组平均，防止大量简单负类主导。

Base内部固定29训练/3内校准/3模拟未见身份开发，完成候选λ及步数选择；不使用外层Cal/Test挑λ。外层35 Base重训，保持预算与数据一致。K=3/5/12使用同一固定注册顺序的嵌套子集，所有方法共享。

固定统计分支不受蒸馏修改，学生单独与融合均报告；尺度和融合参数仅在 Base 内开发。外层 Cal 选择 EER、FAR≤5%两种阈值，Test冻结。公开队列汇总及配对不确定性，逐身份分数/阈值/数据映射保持私有。

固定统计主分支为40维相对谱形状（依据此前探索结果事先指定），另报完整246维统计对照；学生统一输入246维。λ候选0/0.03/0.1/0.3，零权重允许被开发集选中，不强迫 Audio 有效。Base内部选择仅用seed42的12-shot任务，随后锁定λ、检查点步数、融合α及分数均值/标准差，外层三个种子共同复用。融合α候选0/0.25/0.5/0.75/1，零表示不采用学生分支。最终每种学生均训练1000步，再加载预先锁定步数的检查点。

代码中CE统一采用16倍归一化分类权重与L2学生向量的余弦logits，SupCon温度0.1；七种学生完全相同。上述设置区别于未归一化线性logits，应在比较梯度量级时考虑。S0的统计分支不训练神经分类器。

P3规则在首轮最终结果产生前预先固定：S4角度η=0.5；S5全局有偏MMD²采用固定Gaussian σ=0.25/0.5/1/2，学生蒸馏投影后L2；S6逐样本独立选其他训练身份的Audio，不能用统一身份置换，复用S3的λ/步数/α，分数尺度单独由同一Base内Cal构造；S7以固定随机投影的振动输入几何作RKD目标，无Audio、无身份监督目标，不使用无意义白噪声刻意削弱控制。S4/S5/S7沿用相同内部开发网格。
