# U4保存频谱归一化对照

四组：全训练集统一标量zscore；逐样本zscore；两者可学习标量门控；逐样本zscore加保存频谱mean/std/RMS/range双分支。双分支统计量也只用训练行拟合标准化。所有用户使用相同规则，无逐用户前端。

沿用上一轮九身份CE编码器（不是个人CycleGAN），180条/人编码器训练、20注册、30验证、20校准、47–50最终，严格按推断词组划分，三seed42/43/44。本轮目标只报告U4认证，全部八个攻击来源。验证检查点仍按九用户宏HTER，与前轮一致，不能称U4个性化训练。

每组同初始化、minibatch、400步、AdamW3e-4、相同128维编码器与CE9头；增加的4→128无偏统计分支在其他组输入恒零，保持相同参数数量与随机初始化序列。门控g=sigmoid(theta)，输入g*global+(1-g)*instance，初始0.5，只训练更新。双分支为normalize(encoder(instance)+Linear(standardized_stats))。

后端不变：余弦K3/5/10/20，RBF20本人160背景，参数验证选择，阈值在独立校准集平衡FAR/FRR。最终测试不选方法、删人或调整阈值。逐组结果并列报告，不将最终最好组称部署选中组。

重要限制：旧保存数组已归一化至[-1,1]，旧前端统计来源未完整追溯。新增全局统计只用本轮训练，但无法撤销旧归一化。第四组只有保存频谱的相对统计，不是原始传感器绝对能量；本轮不能回答真实能量是否有身份价值。找到的Data0723原始ACC只覆盖chengkeyi、wangjingmei，尚无九用户逐行映射，不能混合两种来源伪造完整原始对照。历史单会话、身份已知、词序推断及尾部缺行限制仍适用。
