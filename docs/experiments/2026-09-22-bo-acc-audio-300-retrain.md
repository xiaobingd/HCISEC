# bo 使用完整 acc/audio 数据重训

- 实验 ID：`bo-acc-audio-300-retrain-20260922`
- 日期：2026-09-22
- 状态：训练中
- 目标：使用 AutoDL `meiy/1/acc.npy` 与 `meiy/1/audio.npy` 重跑 bo 的 CycleGAN 流程
- 数据规模：acc/audio 各 300 条，形状均为 300×80×81
- 训练轮数：200 epoch
- 数据隔离：原始数据只在 AutoDL 远程实例内读取，不提交仓库

## 与旧 bo 实验的区别

旧实验使用 `acc1.npy` 与 `audio1.npy`，各 150 条。本实验使用完整的 `acc.npy` 与 `audio.npy`，各 300 条。

旧模型和旧结果不会覆盖；新模型、日志和检查点写入远程文件存储盘的独立目录：

`/autodl-fs/data/cyclegan_bo_acc_audio_300_20260922/`

## 当前步骤

1. 已确认输入文件存在且形状匹配。
2. 已生成使用完整 acc/audio 输入的独立训练脚本。
3. 已在 screen 后台启动 200 epoch CycleGAN 训练。
4. 待训练完成后，再训练与该新 bo CycleGAN 绑定的独立认证头。
5. 最后使用相同固定验证协议重新计算 bo 的 FAR、FRR、EER、平衡准确率和准确率。

## 原因

bo 原有样本量只有 150 条，而其他用户约有 297–300 条。使用 bo 目录中完整的 acc/audio 文件重跑，可以判断 bo 的高认证表现是否来自较强的个体可分性，还是受到样本量和旧数据子集影响。
