# 九用户开放集认证：Audio微调教师，固定β=0.5

日期：2026-11-05。

每折七个base用户训练Audio教师及ACC学生，一个独立校准身份，一个未见目标身份。目标用户全部样本排除出教师/学生训练、模型超参选择和阈值校准；目标用户只使用enroll部分K-shot注册和final部分测试。全部八个攻击来源保留。10–300Hz三轴速度谱；Audio ECAPA微调后冻结；ACC ResNet18 192维，CE+0.1SupCon+0.5cosine KD，200步，训练用户开发词选检查点。K=1/5/10/20，各10次注册抽样。阈值在独立校准用户K=5分数上按EER选取。未按目标测试结果选择beta或频带。部署使用ACC及余弦注册原型。

修正旧代码目标身份出现在校准负类的问题。词标签来自时间顺序推断，缺失录制位置需语义复核；这些是探索性结果。qis为qisis别名。固定β与此前自动选择β结果不可混为同一设置。
