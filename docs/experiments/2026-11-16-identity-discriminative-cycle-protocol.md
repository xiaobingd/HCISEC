# Identity-Discriminative CycleGAN：阶段A共享编码器

研究问题：在ACC→Audio生成器input256施加身份判别损失，是否优于普通生成训练、单纯身份训练以及冻结编码器后训练投影头。

全部Mei9包含U9。复用冻结的原始前端与划分：fit1438、develop36；每人注册12、CalA/B各4、同词查询16、跨词查询24。fit与认证角色互斥。词语仍按采集顺序推断，尚未逐条语义核验。所有九身份参加共享训练，所有八个攻击来源保留。此轮不是开放集。

G.encoder不改结构：三轴40×32频谱→128通道特征图→均值/标准差池化256维→L2；临时九分类头仅训练时使用，CE和SupCon梯度回传编码器。每批4人×共同2词×每词2条不同录制，全部取fit。第一轮标准SupCon；可独立设置crossword模式仅限制跨词正对，负类仍为其他身份，采样确保有异人同词负对。

|实验|训练|编码器梯度|
|---|---|---|
|E0|归档Audio辅助baseline312，固定参照|本轮不更新|
|E1|LSGAN+10 paired L1+10 cycle L1|生成损失|
|E2|相同G.encoder，仅CE+SupCon|身份损失|
|E3|E1+0.1CE|生成+身份|
|E4|E1+0.1CE+0.1SupCon|生成+身份|
|E5|冻结本种子E1，训练256→256投影及身份头|投影更新，G.encoder冻结|

生成器种子42/43/44，每组4000更新，batch16，相同均衡采样、初始G.encoder、Adam学习率2e-4，后半程线性下降，固定使用4000步检查点，避免不同选模指标混淆。E0是归档seed42固定模型，并非三个新教师/学生种子；报告不能把本轮误写为端到端全流程三种子。E2/E5使用身份损失，不计算生成指标。E5增加投影参数，是后处理控制，参数量不与E2严格相等。

阶段A不做个人微调。每个共享模型只用fit拟合编码特征StandardScaler。输入编码L2后与固定baseline312拼接；alpha=0/.25/.5/1由CalA设阈值、CalB九人平均HTER选定。锁定后提取查询特征，最终阈值用CalA+B设定。另报告encoder-only与E0，RBF固定C10/gamma=scale/balanced、108注册录制拟合。每用户同时报告Cal-EER、Cal-FAR5的TAR/FAR/HTER及分数EER。EER用于事后评估，不用于选择模型或阈值。

训练日志记录CE、SupCon、paired/cycle损失；首次身份梯度范数必须大于0。开发录制另记录Audio/ACC paired L1及两向cycle L1。每250步保存模型、优化器和采样器状态，可断点续训。实现检查使用合成随机数据验证E2/E3/E4的编码器梯度及参数确实变化，不产生科学实验结果。

先比较E4与E1、E2、E5和E0的同词/跨词宏EER、校准HTER及逐用户FAR，再决定是否进入阶段B。阶段B个人100步生成微调、编码锚定及开放用户评估尚未启动，不能混入阶段A结论。最终查询已被历史实验观察，结果属于探索性复现实验。

执行环境优先CUDA，当前实例无GPU、2GB内存，CPU允许但完整三种子耗时较长。执行入口experiments/identity_kd/identity_discriminative_cycle.py；不要把运行中任务写成已完成或预填指标。
