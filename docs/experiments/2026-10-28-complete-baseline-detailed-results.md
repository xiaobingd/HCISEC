# 完整baseline详细实验结果（2026-10-28）

本文只汇总完整772维特征的baseline，不把教师补充、diffusion、紧凑投影、多原型或SVDD作为baseline。分三套协议列出，禁止跨协议拼接最好指标。

## 一、最近对比头实验的强基线：完整772维＋RBF

冻结每目标已有个人G/F。特征为输入浅层128＋瓶颈均值/标准差512＋循环有符号差分浅层128＋差分统计4，共772维；不经过旧512维融合头，也不加入教师。训练后标准化，除sqrt(772)，使用balanced RBF-SVM。

上游随机150条与认证隔离。每人认证60条训练、30条校准、余下测试。目标二分类训练本人60、其他八人480；校准本人30、攻击240。所有八个攻击身份均为已知负类且完整保留。

SVM C=1/10/100、gamma=scale/0.1，在540条认证训练内按词分组5折平均AUC选模，每折重拟合Scaler。阈值只由校准集选择：先最小abs(FAR−FRR)，再最小HTER。模型确定性，baseline只运行一次seed42；不能写成三seed均值。

## 四、如何理解这些结果

1. 近期闭集完整特征＋RBF比旧神经头表面更好，但数据量、划分、样本角色和阈值机制一起变化，不能把差异全部归因于SVM优于SupCon。
2. 完整baseline中U1明显容易区分，U4/U5仍存在较高错误率；开放集下U2/U5/U7的泛化依然不足。
3. 第一节所有八个攻击身份参与过认证训练，不能称开放集结果。第三节才留出U3/U8。
4. 浅层和瓶颈来自输入ACC在G内的编码，不仅是循环ACC；完整baseline能认证不等于已经证明身份信息经过Audio再回ACC得到增强。
5. 所有结果均为既有录制上的探索结果，没有因为质量差或被误接受而删除最终查询。认证训练/校准/最终索引与上游开发数据隔离；但词映射仍依赖尾部缺行假设。
