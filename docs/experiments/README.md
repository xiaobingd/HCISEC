# 实验记录规范

本目录记录所有实验的可追溯信息，包括：

- 实验目的、假设和变更原因
- 时间、实验批次、代码/配置版本
- 用户范围与模型绑定关系
- 训练或验证进度、资源状态和异常
- 仅限汇总级结果、模型文件 SHA-256 和复现说明

## 实验完成记录要求

每次实验完成、失败、停止或发生实质修正后，都必须在 GitHub 中追加或创建实验记录，至少包含：

1. 实验 ID、时间和状态；
2. 目的、假设和成功判据；
3. 数据入口、用户范围和数据隔离边界；
4. CycleGAN、认证头或其他模型的绑定关系；
5. 数据划分、随机种子、训练轮数和关键配置；
6. 每一步操作、结果和原因；
7. 训练/验证/测试样本数量及交集核查；
8. 异常、停止原因和修正措施；
9. GPU、磁盘和运行资源摘要；
10. 脱敏后的逐用户指标、宏平均指标和置信区间（如有）；
11. 模型和关键输出的 SHA-256；
12. 局限性、可复现实验方法和下一步。

实验完成后，必须同步更新相关汇总表，明确标注：

- 当前结果是否为最终结果；
- 是否存在被修正或废弃的旧结果；
- 新旧结果是否可直接比较；
- 使用了哪一个数据加载器和哪一版模型。

## 可保存到 GitHub 的实验结果

允许保存：

- EER、FAR、FRR、准确率、平衡准确率等聚合指标；
- 用户级和宏平均统计；
- 样本数量、交集计数和数据隔离核查结果；
- 训练日志摘要、异常原因和资源摘要；
- 模型文件 SHA-256、配置摘要和复现说明；
- 脱敏后的混淆矩阵或用户×用户聚合误接受矩阵。

禁止保存：

- 原始用户数据；
- 原始样本、特征数组或可逆推出样本的中间文件；
- 用户凭据、SSH 密码、Token；
- 未脱敏的路径、日志或截图；
- 模型二进制文件或可用于恢复用户数据的文件。

## 数据隔离

禁止提交：

- 原始用户数据
- 原始样本、特征数组或可逆推出样本的中间文件
- 用户凭据、SSH 密码、Token
- 未脱敏的路径、日志或截图

用户数据只在远程训练实例内按用户隔离读取。仓库中只保存脱敏后的统计结果和必要的哈希值。

## 每个实验条目的固定字段

1. 实验 ID 与时间
2. 目的和假设
3. 数据隔离边界
4. 模型/认证头绑定关系
5. 配置与代码版本
6. 每一步操作、结果和原因
7. 资源与异常记录
8. 汇总指标
9. 复现方法与限制

后续实验结果必须追加到对应实验条目，并在每次实质进展、失败、修正或完成时更新。
