# 实验记录规范

本目录记录所有实验的可追溯信息，包括：

- 实验目的、假设和变更原因
- 时间、实验批次、代码/配置版本
- 用户范围与模型绑定关系
- 训练或验证进度、资源状态和异常
- 仅限汇总级结果、模型文件 SHA-256 和复现说明

## 数据隔离

禁止提交：

- 原始用户数据
- 原始样本、特征数组或可逆推出样本的中间文件
- 用户凭据、SSH 密码、Token
- 未脱敏的路径、日志或截图

用户数据只在远程训练实例内按用户隔离读取。仓库中只保存脱敏后的统计结果和必要的哈希值。

## 每个实验条目的固定字段

1. 实验 ID 与时间
2. 目的和假设
3. 数据隔离边界
4. 模型/认证头绑定关系
5. 配置与代码版本
6. 每一步操作、结果和原因
7. 资源与异常记录
8. 汇总指标
9. 复现方法与限制

后续实验结果必须追加到对应实验条目，并在每次实质进展、失败、修正或完成时更新。
