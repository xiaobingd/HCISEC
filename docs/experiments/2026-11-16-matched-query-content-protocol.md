# 固定查询、只改变注册词的同词／跨词对照

目的：检查此前跨词HTER低于同词是否来自查询词组不同。本轮同词与跨词条件使用完全相同的物理查询录制、身份标签和攻击来源，只改变注册词。

复用九人训练的冻结模型与训练词Scaler，不重训编码器/教师。U5仍参与原模型训练和负类注册，作为攻击者保留，只在目标宏平均中排除U5，统计其余八人。

最终六个名义词：24 Down、25 Up、26 Zoom、27 Record、28 Play、29 Reset。每词约10次重复，不能构造12条独立同词注册，因此严格逐词采用K4注册、K4查询。折0注册重复0–3、查询4–7；折1交换。每个查询词遍历其余五个注册词，得到30个有向异词组合。

对每个查询词q和异词注册词r：

- 同词：用目标用户q的4条注册，验证固定q查询集；
- 跨词：用目标用户r的4条注册，验证同一个q查询集；
- 查询集始终含目标4条、其余八人各4条。两条件同样36条查询，不因条件删除攻击者。

方法为原始ACC统计＋balanced RBF(C10,gamma scale)，以及冻结local/audio神经验证器。RBF使用对应注册词每个身份的4条样本拟合，每目标4正32负。所有原始统计Scaler沿用词0–17训练，最终词不拟合Scaler。

阈值：Cal词21–23上进行相同的逐词任务，使用同词与跨词同等权重的分数池，按预先固定的Cal-EER规则拟合每目标/方法/折的一个阈值。最终同词与跨词共用该阈值，最终词不调阈值。每折Cal的注册/查询录制也互斥。

输出六词30方向、两折的宏平均；逐词、逐目标及原两组三词A→B和B→A分别报告。A=Down/Up/Zoom，B=Record/Play/Reset。每个方向中同词和跨词始终共用查询，避免此前查询词不一致。

先按词对计算指标，再等权平均；不先平均五个异词分数，否则会给跨词额外集成优势。同词查询被重复用于五个配对比较，不把这些重复当作独立物理试次。两折不构成新会话。

核查：所有配对的查询索引完全相同；同词注册与查询互斥；Cal与最终词互斥；支持数一致；阈值在条件之间共享；模型/Scaler源文件SHA记录；保存分数重算全部2880个工作点。后者为重放核查，不是独立实现整个评分网络。

解释：主问题看原始ACC＋RBF；local/audio原本K12训练，本轮K4只作冻结模型迁移诊断。本轮绝对数值不与旧K12直接比较。内容变化同时改变注册录制，词语顺序、单会话和未经独立转写核验的词标签仍是解释范围。
