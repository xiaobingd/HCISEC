# 振动可观测Audio监督：先验证可预测性，再验证认证收益

2026-11-09。依据用户提出的F0、浊音/周期性、包络和共享频带路线，不再预设完整ECAPA192维均可蒸馏。

研究假设：保留振动身份主任务，增加真实可观测的Audio动态辅助监督，相比BC-only和全局声纹蒸馏改善未见身份认证。可预测性只是必要诊断，不是身份收益证据。

本地HMD的10–300Hz是既有预处理截取范围，不是已经验证的传感器有效频响。既有数据为三轴速度，不能直接当成原始硬件加速度；需结合采集代码、实际时间戳采样和设备滤波确认是否可观测声带周期性。ESMB频带结论不直接迁移给HMD。

第一门禁：仅用4Base(0005/0006/0007/0021)原始AC/BC双通道训练片段估计频率相干性、错误用户相干性、包络时间偏移。用Base训练的轻量BC→Audio回归，在4个独立Cal身份(0022/0023/0026/0027)上检查周期性、F0、包络和共享谱的预测。0024/0025及其Audio本阶段完全不访问。正确配对、同人错时、异人错配使用同样回归容量与训练预算。

原BC旧前端为0–8kHz线性谱257频率点压缩到80行，不能因输入80行就声称保留了清晰F0/低频谐波。物理目标从原始同步波形计算；后续需比较原前端与更高低频分辨率前端，避免把前端收益误归因教师。

F0暂用50–500Hz归一化自相关候选，64ms窗/16ms步长，仍可能倍频/半频错误。归一化自相关峰值不是校准浊音概率；须配合能量门控和置信度，不把静默帧强赋予F0标签。包络测得的最优滞后可能包含设备处理延迟、滤波、窗函数和发音效应，不能解释成组织机械传播时间；不凭生理叙述自行增加延迟。

共享频带仅依据Base真实配对相干性超过错配背景选取。频率相干性不能单独证明骨传导独占路径；ESMB可能含其他共同激励/声泄漏。幅度、相位和频响不能直接由低分辨率归一化图像反演。

第二门禁：在同一新训练输入和身份划分上比较T0(无Audio)、T1(ECAPA192)、T2(F0/周期性/包络)、T3(Base选定共享时频谱)。学生骨干、优化预算、注册/query、负类与阈值规则一致；辅助预测头必须在训练时连接编码器，不能把冻结向量上新加一个回归头称为身份编码器蒸馏。T0/T1也要使用相同新前端重新训练；不得只重训T2/T3后与旧缓存做因果比较。

身份保持损失是主目标；物理目标提供辅助，不要求逐点恢复不可观测的Audio。周期性和发声活动可能主要反映内容/状态，须检验是否只是减少错误迁移，而非增加身份信息。

固定正确配对、同人错时、异人错配对照；所有配对策略与特征筛选不使用最终目标测试。Cal用于选择预定配置及阈值，两个最终目标身份仍完全留出。ESMB没有核实文本，因此不得称严格跨内容。增加Base身份需要重新训练并重新锁定T0/T1，不能复用不匹配的划分。

T2/T3不如T0：不支持身份收益；超过T1但未超T0：只支持减少负迁移；稳定超过T0且通过错配控制：才构成进一步身份知识迁移证据。T4学习式共享教师在此之前不投入大规模训练。
