# ESMB 统一预处理与 RBF 认证对照

本轮先验证预处理对认证的影响，不称为严格同内容或跨内容，也不替代完整772维基线、神经T3模型。现有双通道长录音没有窗口级可靠文本，不能以时间索引相同推断句子相同。没有找到现有语料目录内的逐句转写。

## 数据与隔离

复用扩大T3的14个规范身份文件与身份角色：7 Base、2 Cal、5未见目标，一身份一文件。主实验沿用此前更正的 channel1 输入；复查历史更正脚本发现，该模态标签来自用户当时更正，脚本明确记录未由官方文档独立确认。此次 channel1 高频/低频能量比大于 channel0，是需核查的信号，不能仅据频谱定模态。补跑 channel0 完全匹配对照；通道确认前统一使用物理通道名，不按认证成绩选择哪个是BC。

16kHz，每3秒取2秒，共240窗。Base每人前120窗为背景负类；Cal/目标前120窗仅用于各自认证头注册；最终查询为索引200–239，与注册区间不重叠。Cal只选择阈值，目标标签不用于选择参数。每个目标40本人查询，其他4位目标各40条攻击，共160条未见攻击。不删难用户、不按测试质量选样本。窗口仍来自同一录制，不等价于跨session验证。

## 三组处理

统一去均值，1024点Hann窗、256点hop、2048点FFT。将对数功率插值到50–1200Hz的40个几何频率中心，避免低频窄分箱没有FFT点。此频段用于特征选择，不是对原始文件做100–500Hz硬带通。

每频点取时间均值、标准差和四段均值，共240维。三组分别为：原对数谱；每条原始窗口做单个标量均值/标准差归一化后的谱；归一化谱加5维原始能量/幅度分位数统计。所有身份使用同一规则，没有按个人设滤波器。输入标准化只在Base前120窗拟合。

认证为每目标独立 balanced RBF SVC，固定C=1、gamma=scale；本人120正类、7Base共840背景负类。两Cal身份各自模拟注册/相互攻击，汇总分数按Cal EER平衡规则选一个统一阈值；同EER差值时优先较低Cal FAR。目标只拟合注册头，随后一次评分全部目标查询与攻击。

检验原始配对PCM重复；发现完全重复则停止。监测削波和RMS，不根据最终认证表现剔除。只公开宏平均和总体计数，原始数据、逐身份结果、阈值保留私有。

## 解释边界

这是一轮确定性、手工频谱前端的预处理诊断。幅度保留若明显更好，可能涉及有用生理幅度或录音增益/佩戴差异，单凭本轮不能区分。归一化有效也不证明提取了内容无关身份。需要可靠文本和独立录制验证才能支持这些结论。两Cal身份的阈值迁移覆盖有限。

运行脚本：`experiments/identity_kd/run_esmb_preprocessing_rbf.py`。

## 初步 channel1 结果

|处理|本人接受率|未见攻击FAR|HTER|AUC|
|---|---:|---:|---:|---:|
|保留幅度，全局标准化|91.00%|8.75%|8.875%|0.95722|
|逐窗口归一化|89.50%|3.00%|6.750%|0.98094|
|归一化加原始能量统计|89.50%|2.625%|6.5625%|0.98222|

各值为5个目标宏平均；未删攻击来源。3,360个配对窗口未发现完全重复载荷；最高窗口削波比例0.01875%。三组同划分、同阈值选择规则，但各组的实际Cal阈值独立选择。约83秒完成，不是重训生成器或神经编码器，而是固定特征上的小型SVM。

这里支持的有限结论是：在当前channel1输入和同session协议下，逐样本规范化降低了误接受，补充能量统计有小幅增量。不能据此证明内容无关、Audio蒸馏收益，或在通道尚未核实的情况下确定称为BC认证。

## channel0 对照已完成

|处理|本人接受率|未见攻击FAR|HTER|AUC|
|---|---:|---:|---:|---:|
|保留幅度，全局标准化|90.50%|4.50%|7.000%|0.98422|
|逐窗口归一化|84.50%|2.625%|9.0625%|0.98838|
|归一化加原始能量统计|87.00%|2.625%|7.8125%|0.98941|

约81秒。这里规范化虽降低FAR并提高排序AUC，却增加本人拒绝，HTER未超过保留幅度组。因此不能只看FAR宣称归一化在所有输入上都更好。channel0最高窗口削波比例约1.028%，本轮未据此删除数据。

下一步应独立确认物理通道并核验内容，再将候选处理放入同前端的T0/T3训练对照。这两路结果不证明Audio辅助有效，亦不改变旧T3未核实通道/文本的证据边界。
