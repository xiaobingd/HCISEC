# Mei9：Audio决策蒸馏与跨词神经验证器（首轮）

## 任务与来源

创新点一的CycleGAN方法单独保留。本实验为独立方法：Audio只参与离线训练，注册与查询仅使用HMD振动输入。主任务为九个已知身份的闭集跨词认证。

方法依据为2026年短语音神经重评分论文（https://arxiv.org/abs/2606.16115），采用注册—查询双向帧级交叉注意力。本实现使用单层128维4头注意力、时间均值池化和注册集合均值/标准差；不复现原文同文本/异文本混合注册，不在跨词查询中加入同词注册。

新Audio教师为ReDimNet2-B3，官方VoxCeleb2 large-margin权重。固定官方代码版本c5bbe0b76e37df698c403f8844e41304ceab6307，权重SHA256为02d14efdc184573873b5c3f62bea847fcdb6919fbba19a8da7af7c1ba36b76a2。教师主干冻结，不进行本地最终词微调。官方实现：https://github.com/PalabraAI/redimnet2 。

## 数据与隔离

沿用同一2695条九用户统一前端：OpenVR vVelocity三轴，时间戳插值1kHz，2秒，逐轴DC移除，256窗/64hop/1024FFT，40个10–300Hz频率点，28帧。此为跟踪速度信号，不冒充硬件原始加速度。1kHz插值率不证明模拟传感器带宽。

词标签仍为采集顺序映射，未逐条语义转写核验。缺行不填充，不按成绩删用户或样本。

|词编号|用途|
|---|---|
|0–17|ACC编码器、分数基线、验证器、训练Audio|
|18–20|模型开发，仅ACC|
|21–23|阈值校准，仅ACC|
|24–26|每词前4条注册、另4条同词查询|
|27–29|每词前4条跨词查询|

训练、开发、校准和最终评估池的词及录制互斥。最终注册12条，同词/跨词本人查询各12条；八个攻击身份均保留，每目标每条件96条攻击查询。各用户使用相同内容集合。任务数不是独立物理录制数。

训练、开发及校准任务均使用12条注册支持（两个词各6条），查询来自第三词；最终注册使用三个词各4条。支持总数相同，词数不同。训练任务3600、开发900、校准1800，均为固定采样的重复使用任务；按轮转覆盖全部八个攻击来源，不依赖随机采样是否抽到。

## 模型及预算

ACC编码器：Conv2d 3→32→64→128、GroupNorm、GELU，频率步长2，保留时间维，输出28×128。仅使用训练词身份CE训练400步后冻结，九分类头不参与认证。频谱标准化仅拟合训练词；原始720维统计Scaler也仅拟合训练词，随后L2归一化。

基础分数由原始统计的注册—查询余弦均值/标准差/最大/最小及注册中心相似度构成，训练词任务上拟合LogisticRegression形成logit。神经验证器输出有界残差：s=s0+tanh(R)，最后一层零初始化。

|方法|说明|
|---|---|
|raw_pair_score|原始统计配对Logistic评分|
|raw_rbf|原始统计＋balanced RBF C10 gamma=scale|
|global|全局相似度MLP残差，无局部注意力|
|local|加入注册—查询双向交叉注意力，无Audio|
|audio|local＋ReDimNet2决策概率蒸馏|
|shuffle|同用户内打乱训练Audio记录，重建相同评分流程|

神经组相同seed42初始化及任务批次，AdamW lr3e-4/wd1e-3，dropout .1，1000步，batch16任务，梯度裁剪1。每100步按开发集宏AUC选检查点，同分保留较早步数。主要对照audio对local，global对local；原始RBF为完整后端参考，不是同结构消融。

损失为BCE＋0.1*T²*Bernoulli-KL＋0.01*残差平方，T=2。global/local不含KL。没有TRKD、SupCon、Audio特征矩阵RKD或新CycleGAN训练。

## 教师目标

只读取词0–17的原始Audio，按原始数组SHA核验，48kHz左通道统一下采样16kHz、DC移除。ReDimNet2输出192维。查询、注册、开发及校准词Audio不读取。

教师匹配评分器为相同五种相似度统计的LogisticRegression。按训练查询词编号模3交叉拟合：某折目标的评分器训练任务不含该折任何词。教师主干为外部预训练冻结模型。该过程是评分器交叉拟合，不是重新训练整个教师的交叉验证。

打乱组保留用户身份、破坏具体录制及词语对应；用于诊断精确内容对应，不能将其解释为错误身份教师。

## 评价与实现状态

每用户Cal-EER规则固定阈值，同词/跨词共用，报告TAR/FAR/FRR/HTER、AUC及描述性Test-EER。神经组在Cal模拟注册任务确定阈值；RBF参考在最终合法注册样本拟合，使用Cal查询词选择阈值。两种后端校准支持构造有差异，不将差值全部归因于特征质量。

首轮只跑一个种子和上述四种神经配置。ECAPA教师替换、传统特征蒸馏匹配对照及多种子尚未纳入，不能宣称已完成全部原规划消融。该批为历史已探索数据上的方法试验，尚非新会话确认实验。

基础检查已通过：零初始化保留原始分数；注册排列不影响结果；注意力梯度非零；训练注册/查询异词；所有攻击来源覆盖；真实训练录音可通过官方ReDimNet2前向。状态与最终成绩分开记录，训练启动不代表方法已有效。
