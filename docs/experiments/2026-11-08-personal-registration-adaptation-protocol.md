# 未见用户注册期个人判别适配：固定实验协议

先固定协议再执行。通用ACC编码器复用24个严格Base-only ResNet18检查点，冻结；不使用曾见目标身份的本地主干。8目标×3种子，每折4Base、2Cal、目标与未见攻击者互斥。

各个人任务使用12条本人注册正样本、4位Base各12条共48条负样本。负类与该任务注册正类采用完全相同的3词×前4次录制，避免内容差异捷径。查询为同词/跨词协议的每词后4次，训练与查询sample_id完全不重叠；不删除任何攻击来源。注册时知道其本人身份，不需要最终查询标签。

方法：原余弦模板；个人193参数线性头；线性头+192参数对角残差；同样残差+ACC自身一致性控制；同样残差+同步注册Audio约束。残差为norm(z*(1+0.1tanh(gamma)))，gamma零初始化。Audio教师及其Base-only Audio→HMD映射冻结，Audio只取本人12条注册录制，作用于适配后正类表示；不读查询Audio，不增加Audio组可训练参数。

适配固定200步、全批12正/48负，balanced BCE+0.001mean(w²)，残差组再加0.01mean(tanh(gamma)²)。head Adam学习率0.02、adapter0.01，自身/Audio余弦约束权重均0.1。初始化和预算相同，无目标开发集早停、无最终标签选择参数。12个独立个人任务向量化：每任务参数独立，损失求和保留各自梯度尺度，不分享个人梯度。

校准身份也只用各自12条注册+同一Base48负适配个人模型。**主校准协议**：两位Cal彼此作为未见攻击者，避免已参与个人负类训练的Base占据校准负类。**旧混合校准仅作预先固定的次要对照**，含Base与另一Cal，原余弦应完全复现P1。两套协议都完整报告，不看最终结果挑选；不能把换校准池带来的变化当作个人头收益。

每方法、每校准协议分别采用Cal EER和经验Cal FAR<=5%两个事先确定工作点。同词/跨词共用其方法阈值，目标/未见攻击者不参与阈值确定。Cal FAR<=5%不保证新攻击FAR。主校准合并96个genuine和96个impostor分数，存在共享录制与模板重复，不是96位独立攻击者。

主终点为跨词、严格未见攻击者，逐用户宏平均后报告三个种子的均值/标准差；再列全部七来源（其中Base四位是个人训练负类身份，需明确）和同词。两种现有冻结Audio编码器独立对照；不混入尚未完成的本地Audio主体迁移模型。

限制：词标签按采集顺序推断未逐条语义核验，八人群体排除yue有探索性选择；个人适配允许新用户合法注册训练，不等于目标身份在部署适配阶段仍完全未见。只有通用模型/规则的离线训练与目标隔离。
