# 严格未见身份、选择性蒸馏与同词/跨词对照

状态：协议及执行代码完成；已启动服务器训练，未形成正式结果。禁止将先前八个已见身份的指标标作本轮开放集结果。

## 身份与数据隔离

八用户（此前已按用户要求排除 yue，属于探索性选择的人群），每人轮流作为最终目标。环形顺序中下一个用户为未见攻击者，再两个用户为阈值校准身份，其余四人为表征训练身份。八折均预先固定，不按测试效果换人。目标和未见攻击者均不参加归一化统计、编码器训练/开发、残差训练/开发、选择性蒸馏规则或阈值校准。

每折重新初始化纯 ACC ResNet18，192维归一化输出，CE+0.1SupCon，200步；仅四个训练身份的fit录制参与更新，develop录制选择检查点。三个训练种子42、43、44，共24个编码器训练任务。不得复用已见八人或九人的本地主干。

冻结Audio教师沿用仅在VibraVox上训练的ECAPA，不使用在本地九用户上微调的教师。现有Audio缓存仅取本折训练身份的fit行。

## 方法对照

- 原编码器：无残差。
- 仅身份残差：192→64→192，末层零初始化，修正范数≤0.1；身份分类、SupCon、原表征保持。
- 均匀Audio关系蒸馏：同人/异人关系误差分别归一化，等权平均。
- 针对性Audio关系蒸馏：只从训练身份fit录制计算跨词身份中心关系；选取“ACC混淆排名高于Audio”的正差距关系，最多取全部身份对前三分之一，并要求Audio同人跨词相似度高于该异人关系。选中异人关系权重2，其余1；各类归一化，保持全局监督强度一致。禁止按已观察到的bro–jin名称指定或根据目标测试分数选边。

三个残差组相同初始化、批次、1000步预算和开发集选择规则。初始无残差检查点允许被选择。

## 同词/跨词单变量对照

只用历史final六词：Down、Up、Zoom、Record、Play、Reset。每人每词取共同前8次，分两组三词，两个方向轮换：

|项目|同词|跨词|
|---|---|---|
|注册|查询词组三词各前4次，共12条|另一词组三词各前4次，共12条|
|查询|固定查询词组三词各后4次，共12条|完全相同的12条查询|
|编码器/残差|完全相同|完全相同|
|后端|12-shot单位化均值模板+余弦|相同|

阈值分别在两位独立校准身份上按条件确定；校准攻击仅来自训练身份及另一位校准身份，不包含最终目标和未见攻击者。条件阈值选择算法、校准样本数一致。每目标两方向汇总24条本人查询，严格未见攻击者24条；另报告全部七来源攻击（包含训练/校准中已见身份，须单列）。

该后端服务于未见用户注册，不能与旧的、使用目标负类训练的闭集RBF头混为同一协议。同词/跨词只改变注册词集合，没有再次训练不同编码器。
