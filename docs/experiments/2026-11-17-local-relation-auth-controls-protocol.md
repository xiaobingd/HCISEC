# B0–B3：Audio局部关系能否改善ACC-only未见词认证

本轮是三个随机种子的探索性对照。词12–17已经在前轮查看，不能当作新预留确认集。创新点一V1、已有模型和历史结果均不改动。

## 数据与预算

全部九人，不选人。词0–11每人每词前6条（648条）训练编码器及构造关系，重复6–7（216条）只用于校准查询。词12–17每格前8条（432条）用于未见词注册/查询。词/重复语义仍为历史名义映射。

标准化重新拟合648条训练ACC；局部教师只用这648条同步训练Audio，没有校准或验证Audio监督。所有方法共享相同编码器结构及数据规则。

seed42/43/44，每seed从随机权重共同CE预训练400步，再复制到四组各继续400步，合计每组800更新。分支AdamW都重置，lr3e-4/wd1e-3/clip1，batch36（9人×2相同词×2次重复）。同seed四组续训批次完全相同；固定末步，不选检查点。CPU线程数4来自无数据的运行速度测试，不依据认证结果。

## 四组

- B0：仅CE。
- B1：CE＋冻结400步ACC教师的局部自关系；邻居只由ACC训练表示确定。
- B2：CE＋冻结ReDimNet2-B3训练Audio的正确局部关系。
- B3：CE＋错误Audio关系；保留B2相同邻居掩码，每批两词使用不同的非零跨身份移位，保持词/重复序号，破坏跨词正身份关系。

固定局部图：各用户Top2邻居在全训练集、前3/后3重复、偶数/奇数训练词五个视图中的交集。没有稳定邻居时，仅关闭该用户局部关系项，不删除其CE样本、认证目标或攻击来源。B3仍含B2的正确掩码信息，是错误关系值的保守对照，不能称完全无Audio对照。

局部行关系KL温度0.2，仅含同人异词正对与稳定邻居的异人同词负对，不恢复整行关系KL或SupCon。每步将关系项编码器梯度范数匹配CE编码器梯度的3%，lambda上限1，所有辅助组规则相同，不搜索权重。两个autograd结果直接相加更新，不额外做第三次反传。教师detach，身份梯度进入当前编码器。

## 认证与校准

主后端balanced RBF SVC(C10,gammaScale)，128维L2 ACC表示；余弦原型为诊断。注册词每人K4，其他八人同词K4为背景，所有组一致。编码器不更新于注册。

校准：训练词0–11各词前4条注册，第7–8条查询，后者未见于编码器。校准池同词/跨词等权，选择每目标/seed/方法/后端的Cal-EER阈值；锁定后用于全部验证词、两条件、两折。没有本人接受率约束。

验证：六词12–17，30有向异词组合，两折前4注册/后4查询再交换。同词与跨词使用完全相同查询与攻击来源。报告每目标池化EER与固定Cal阈值HTER/FAR/FRR/AUC，再宏平均九人。

间隔：每任务本人平均得分减八个攻击身份中最高的平均得分；另给最差本人减最强攻击样本。以校准攻击分数标准差归一化，并保留原始间隔，防止仅因后端分数缩放误判改进。

## 判读

不以Audio关系Spearman判断成功。报告三seed均值/标准差、每seed的B2−B0/B1/B3差值，以及全部九人的结果。重复词对、共享攻击者和三个优化种子均不能充当独立新受试者。不挑最好种子/用户/后端。

如果B2仅胜B0却不胜自关系或错配，不能归为Audio独立收益；如果只改EER而固定阈值HTER或最困难身份间隔退化，也必须明确报告。任何正向结论仍需新预留数据确认，本轮不会据验证结果重选规则。
