# VibraVox：CycleGAN特征补充对照方案

沿用59人35 Base / 12 Cal / 12 Test、K=12、seed42和原始句子角色划分。保留原始频谱形状40维及个人Audio微调教师V4蒸馏学生192维，新增CycleGAN冻结特征。所有11个攻击来源保留，完整报告12位Test与12位Cal的匿名用户结果。

## 为什么新训共享CycleGAN

旧VibraVox CycleGAN仅为历史两人小样本专属模型，不能直接保证当前59人Base/Cal/Test身份隔离。这次只用35位Base的fit录制预训练共享G（振动→Audio）和F（Audio→振动）。根据用户补充要求，共享模型仅作初始化与对照；每个注册者还要进行下述个人微调。Cal/Test身份不进入共享预训练。每次查询只输入振动，经注册者对应的G/F提取特征。

这是新增紧凑CycleGAN分支，不是重现历史完整772维或原先个人生成器。原始数据是VibraVox单轴额头加速度与头戴麦克风，不是本地VR头显速度信号。

## 前端与模型

- 与现基线相同的中央2秒、去直流、16kHz、4096点Hann、1024步长、16384FFT、50–7600Hz几何40频带log功率。28个时间格统一插值为32格，仅供GAN；原始统计/学生前端不变。
- 每个模态仅用Base-fit计算一个全局均值及标准差，除以3倍标准差并截断到[-1,1]，对所有人使用同一处理规则。
- G/F均为width32、两次下采样、4残差块、最近邻上采样＋卷积的ResNet；PatchGAN判别器；LSGAN＋10倍配对L1＋10倍循环L1＋1倍identity mapping L1。这里identity mapping是信号恒等约束，不是用户身份监督。
- 4000次更新、batch16、Adam2e-4、后一半线性衰减。实际等效轮数按训练录制数量计算，不能称200轮。每250步，在每位Base预定前2条develop录制、共70条上选最低双向配对＋循环MAE检查点。
- query Audio不解包或前向。GAN Audio仅限Base fit/develop。

## 特征候选与对照

1. 输入ACC的G编码器均值＋标准差，256维。
2. 循环ACC的G编码器均值＋标准差，256维。
3. 生成Audio的F编码器均值＋标准差，256维。
4. 循环ACC频谱形状、标准差、相对四时间段统计，240维。
5. 生成Audio频谱形状与标准差，80维。

每个候选仅用Base-fit拟合StandardScaler后L2归一化。固定对照采用[baseline232;0.5×GAN分支]/sqrt(1.25)，各候选均报告。自主选择只允许增加一个分支，权重0.25/0.5/1，也允许不增加分支。Cal01–06选阈值、Cal07–12按HTER/AUC选择分支与权重，负类仅取各自6人子群。锁定后才提取Test的学习型GAN特征，不能按Test更换分支。

增加同架构未训练随机初始化G/F对照：使用相同选中分支/权重及其Base-fit归一化；另固定随机输入编码器0.5权重。用于判断收益是否仅来自随机非线性变换或增加特征，而非学到跨模态关系。

最终每种方法以全部12位Cal分别确定Cal-EER与Cal-FAR5阈值；12位Test每人24本人、264攻击比较。完整逐用户双工作点公开，原始数据、样本分数、阈值、权重和身份映射保持私有。

## 结论边界

同一已探索VibraVox语料、单种子，尚非独立确认实验。跨用户句子不完全相同，因此不能宣称同内容认证。G/F循环误差降低不等于身份保留；需要同时比较原始形状、现232维、GAN补充和随机网络对照。只看到某些Test用户提升不能据此选择发布对象或最终方法。

## 用户补充：注册者单人CycleGAN微调（本次主实验）

- 12位Cal、12位Test分别从同一Base预训练G/F独立重置，禁止沿前一个用户模型继续训练。
- 每人仅使用自己的12条注册振动–Audio配对，额外读取注册Audio共288条，不读取query Audio，不使用其他身份样本参与个人梯度更新。
- G/F同时微调100步、batch6、Adam2e-5，保存25和100步；保持原LSGAN＋配对＋cycle＋identity损失。判别器固定为共享训练最终步的Base-only判别器，不在12条数据上重新学习，所用G/F为Base-dev选择检查点。
- 各个人模型及所有阶段沿用共享Base-fit输入归一化和共享Base-fit特征StandardScaler，禁止在注册或查询上重新拟合尺度。
- 先为12位Cal完成25/100步模型。Cal前6位定阈值，后6位在两阶段×五分支×三个权重及不补充分支中选择。锁定后再训练Test个人模型，不按Test选择微调步数或特征。
- 固定对照报告25/100步的输入编码、循环编码及循环频谱三种分支，权重0.5；另报告个人自主选择、匹配分支/权重的未微调共享模型和随机网络。共享模型单独实验只作参考，不代替个人模型主结果。
- 每个注册者模型同时处理本人及全部11位攻击者的query，不能用攻击者自己的G/F来处理攻击样本。检查个人微调是否让不同输入都靠向注册者，防止把目标身份印记误判成身份保持。

这里的“未见用户”指共享预训练未见；注册阶段允许本人少量配对数据进行个人迁移。部署查询仍只需振动输入。
