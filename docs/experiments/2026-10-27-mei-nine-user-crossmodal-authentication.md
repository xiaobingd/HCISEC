# Mei 九用户跨模态身份认证实验汇总

> 实验日期：2026-10-26 至 2026-10-27  
> 状态：已完成探索性验证；**不是统一协议下的九用户最终基准**。  
> 数据范围：Mei 九用户 ACC 与 Audio 配对数组。GitHub 仅保存脱敏后的汇总指标，不保存原始数据、特征或模型权重。

## 1. 目标与实验问题

检查 ACC→Audio 跨模态生成特征能否支持逐用户二分类认证，并比较配对重建基线与身份一致性约束。对目标用户分别训练认证头，判断“本人 / 非本人”；阈值只由认证头训练数据的交叉验证确定。

核心假设：冻结的跨模态身份教师可以给生成器提供身份一致性监督，使生成 Audio 的教师嵌入更接近输入 ACC 的身份嵌入。

## 2. 实验分组与数据隔离

### A. 严格内容子集：U1、U2、U5、U6

这四人的 300 组数据内容序列完整对齐。四用户共享一个 ACC/Audio 身份教师和一个生成器。数据行按录制轮次分配：

| 阶段 | 行位置 | 每用户数量 | 用途 |
|---|---:|---:|---|
| 教师/生成器拟合 | 0–119 | 120 | 训练跨模态身份教师与 ACC→Audio 生成器 |
| 模型选择 | 120–149 | 30 | 选择教师和生成器检查点 |
| 认证头训练 | 150–239 | 90 | 每位目标用户独立拟合本人/非本人二分类头 |
| 最终查询 | 240–299 | 60 | 每用户 60 个本人样本；其余 3 用户共 180 个攻击样本 |

认证头输入为冻结 Audio 身份编码器对生成 Audio 的嵌入。负类是另外三位参与用户。测试行未用于生成器、教师、认证头拟合或阈值选择。

### B. 剩余五人共享模型探索：U3、U4、U7、U8、U9

五人共同训练一个跨模态教师/生成器，按相同的前 150 行做教师与生成器开发、150–239 行训练认证头、240–296 行测试。由于数组实际长度为 297 或 299，且缺失位置未知，数据按共同位置截断；跨用户相同行不能保证对应相同单词。该组只作为位置切分的探索性结果。

### C. 剩余五人个人模型：U3、U4、U7、U8、U9

每个目标用户各自训练其跨模态教师、ACC→Audio 生成器和二分类认证头；教师/生成器权重不在目标之间共享。每个个人生成器使用这五位用户的配对训练数据，并由相应目标用户的二元身份教师提供一致性监督。数据阶段为：

| 阶段 | 行位置 | 每用户数量 |
|---|---:|---:|
| 教师/生成器拟合 | 0–119 | 120 |
| 检查点选择 | 120–149 | 30 |
| 认证头训练 | 150–239 | 90 |
| 最终测试 | 240–296 | 57 |

每个头训练 90 个本人样本和 360 个攻击样本，测试 57 个本人样本和 228 个攻击样本。位置划分没有泄漏，但未知缺行会破坏跨用户严格同词对齐。

### D. 九个独立认证头重训：2026-10-27

加载已保存的教师/生成器检查点，**不重训生成模型**，重新为 U1–U9 分别拟合独立本人/非本人逻辑回归头，并保存头和标准化器。U1/U2/U5/U6 复用 A 组共享教师/生成器；U3/U4/U7/U8/U9 复用 C 组个人模型。认证头训练区间和测试区间与各组原设置一致，重训结果复现了此前认证指标。

阈值用头训练集五折 OOF 分数选取；U1/U2/U5/U6 按已知内容分组折叠，剩余五人按位置折叠。最终测试仅用于报告 TAR、FAR、AUC。

## 3. 模型和配置

- 身份教师：独立 ACC、Audio 卷积编码器映射到归一化 64 维嵌入；共享四用户组用四类身份监督，个人五用户组按目标用户 vs 其他四人训练二元教师。
- ACC→Audio 生成器：ResNet 生成器，hidden=48、4 个残差块、resize-conv 上采样。
- 生成目标：配对 Audio L1 + 0.15 频率梯度 L1 + 0.15 时间梯度 L1 + λ_id × (1 − cos(E_A(ACC), E_M(G(ACC))))。
- 对照：λ_id=0 的配对重建基线；身份引导版本 λ_id=0.5。教师在生成器训练阶段冻结。
- 认证头：每个用户单独一个 StandardScaler + LogisticRegression，C=0.1、balanced 类权重；不是九分类器。
- 统一处理：相同 ACC/Audio 预处理和 80×80 输入裁剪；不同用户没有单独调滤波或归一化方式。
- 训练随机种子：共享组教师初始化 seed=42，生成器 seed=71；个人组按目标用户 seed=2600+user，生成器 seed=seed+71。GPU 环境为单张 RTX 3080 Ti。

## 4. 结果：严格对齐四用户

格式：TAR / FAR / AUC。TAR/FAR 使用训练 OOF 选定的阈值。

| 用户 | 原始 ACC 教师 | 配对生成基线 | 身份引导生成 |
|---|---:|---:|---:|
| U1 | 100.0% / 0.0% / 1.000 | 90.0% / 7.8% / 0.960 | 88.3% / 3.3% / 0.984 |
| U2 | 63.3% / 30.6% / 0.751 | 70.0% / 48.9% / 0.644 | 80.0% / 44.4% / 0.753 |
| U5 | 65.0% / 18.3% / 0.823 | 66.7% / 25.6% / 0.786 | 73.3% / 24.4% / 0.821 |
| U6 | 65.0% / 28.9% / 0.757 | 61.7% / 35.0% / 0.720 | 68.3% / 40.6% / 0.704 |

四用户宏平均 AUC：原始 ACC 0.833，配对生成基线 0.778，身份引导生成 0.816。身份损失在部分用户上改善生成特征，但 U1/U5/U6 的 AUC 没有超过原始 ACC；阈值下 FAR 对用户差异仍明显。

| 用户 | 头训练本人/攻击 | 测试本人/攻击 | 身份引导 TAR | FAR | AUC |
|---|---:|---:|---:|---:|---:|
| U1 | 90 / 270 | 60 / 180 | 88.3% | 3.3% | 0.984 |
| U2 | 90 / 270 | 60 / 180 | 80.0% | 44.4% | 0.753 |

## 7. 可比性、边界和异常

1. U1/U2/U5/U6 与 U3/U4/U7/U8/U9 的生成器/教师训练策略不同；前者共享一个四用户教师和生成器，后者是逐目标个人教师和生成器。
2. 两组最终测试规模不同（60+180 vs 57+228），剩余五人存在未知缺行位置，九人总宏平均不作为正式结论。
3. 同一采集会话内的重复录制划分；未验证跨会话、跨日期或真实部署泛化。
4. 五人个人教师采用目标 vs 其他四人的监督，攻击类只覆盖本次参与的四位用户。
5. 最终九头重训复用了既有教师与生成器检查点，不代表九个用户都训练了个人生成器。
6. 本实验是单向配对 ACC→Audio 加身份损失，不是完整的双向 CycleGAN 循环认证。
7. 认证头检查点和所有模型二进制不上传 GitHub；结果 JSON 仅包含脱敏指标和数据划分信息。

## 8. 复现与后续

复现需在授权实验机上使用相同数据加载器和已保存模型检查点，运行九头重训脚本。认证头训练/测试严格按上述固定行区间，修改用户、分割、数据预处理或特征路由应创建新记录，不覆盖本条结果。

下一步应先统一九用户上游模型策略和样本对齐方式，再开展九用户多次划分/多随机种子认证；在这些条件完成前，不报告混合协议的九用户总体指标。
