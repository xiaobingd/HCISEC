# 创新点一CycleGAN：固定查询的同词／跨词核查

定版来源为mei9_closed_rerun_20261110。共享G/F、每用户本人12条旧注册数据的100步微调、Audio辅助ACC学生和所有Scaler全部冻结；沿用旧Cal选定input256、alpha0.5，不根据新测试重选特征或参数。

首先核验旧实验：注册是词20–23重复0–2，同词查询是同一组词的重复5–8，两者录制互斥；跨词查询是词24–29。旧“同词”名义标签成立，但同词/跨词比较的查询词不同。重算原statistics720/baseline312/selected_cycle的九用户Cal-EER分数与指标，共54项。

新对照最终使用词24–29，六词30个有向异词组合。同词条件注册查询词的独立录制，跨词条件注册另一个词；查询、标签和八名攻击来源完全相同。K4注册＋K4查询，两折交换重复0–3与4–7。每词重复约10次，不能用12条独立同词注册，因此新绝对指标不与旧K12直接比较。

校准固定词21–23：注册重复0–3、查询重复4–7，不交换Cal。原个人GAN与学生蒸馏使用旧注册重复0–2，如果交换Cal会把训练过的录制作为校准查询。因此固定Cal查询并断言其与原fit/dev/register及个人微调索引无交集。最终六词的全部使用录制也与这些训练索引互斥。

每目标/方法只在Cal的同词与跨词同等权重分数池确定一个Cal-EER阈值，全部最终词、两个重复折、两种内容条件共用。RBF C10/gamma scale/balanced，目标4条正注册，其他八身份各4条负注册。个人生成器继续使用历史12条微调权重，本次K4只训练RBF，未新增Audio或个人GAN训练。

方法：

- statistics720：定版原始ACC统计；
- baseline312：原始120维形状＋既有192维学生；
- selected_input256：baseline312＋个人100步G输入编码，固定alpha0.5；
- cycle256_fused：baseline312＋循环ACC再编码，固定alpha0.5诊断；
- cycle256_only：循环后编码单独认证。

input256与cycle256分别报告，避免混淆“循环一致性训练得到的输入编码”与“循环重建后的编码”。

主汇总沿用上一轮六名目标U1/U2/U3/U4/U6/U7；同时给出完整九人。两个范围都保留全部八名攻击者，U5/U8/U9只在主宏平均中不作为目标，没有从攻击源删除。

只读模型文件从原服务器取回，按源SHA256验证；不更改源检查点。原owner1缓存用于比较新提取特征与旧规范索引上的重叠记录。最终分数私有，保存分数重算5400个工作点、查询/注册隔离及阈值共用另行记录。

解释范围：名义词序未独立转写；旧历史单会话数据已探索；词对重复查询、两折重复使用录制，不是独立新样本。此为固定模型的认证内容效应核查，不是新个人化训练方案，也不是未见身份开放集。
