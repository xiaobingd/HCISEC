# 冻结ACC提取加速与完成核验

VoxCeleb初始化及VibraVox ACC两组缓存现均完成2397条，未减少用户、录制或轴。服务器仍为0.5 CPU核、2GB内存，无GPU。

服务器原三轴逐次推理与三轴合批的实测约1.54与1.51秒/条，单纯合批约2%改善；不能宣称显著提速。加入torch.inference_mode、批处理和每8条原子保存进度，保留float32。

为利用独立算力，将冻结推理导出到本地CPU，实测选中4线程，约1.13秒/条；本地负责482条后段，服务器保留1915条前段，两端独立并行。该数字是推理吞吐，不包含模型导出、传输或验证耗时，也不是整个实验加速比。

导出时发现SpeechBrain句级去均值内部.data会导致直接追踪固化统计，第一版未通过一致性检查，未用于提取。将相同的全长句级均值移除保持为动态运算后重新导出；仅支持本实验固定三轴、每轴32000点输入。模型、原始信号、逐样本特征均未公开上传。

服务器端导出校验最大误差0，本地三条校验录制最大绝对误差约1.49e-6。合并时另比较40条服务器/本地重叠记录，最大绝对误差1.0524e-6，通过rtol1e-4、atol2e-5检查。全2397条均有限且为单位向量。合并后恢复原认证对照队列，ACC主干微调仍以冻结对照完成为依赖。

代码：extract_vibravox_acc_transfer.py、export_acc_inference_jit.py、finish_acc_extraction_local.py、merge_acc_parallel_extraction.py，均位于experiments/identity_kd。
