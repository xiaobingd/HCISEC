# Audio辅助跨词身份表征学习：首轮定位实验

状态：已实现并启动seed42；不是已完成的认证结果。创新点一V1完全冻结，本实验独立于CycleGAN。

## 任务与人群

九人参与编码器、Scaler、开发、RBF注册负类与Cal；最终目标和攻击池均为U1/U2/U3/U4/U6/U7/U8/U9，移除U5最终目标及攻击。每目标最终七名攻击者。这与第一点定版的人群口径一致，但不是重新使用第一点的模型或绝对基线数值。

统一前端2695条三轴OpenVR vVelocity频谱3×40×28，保留原始统计720维。每频点/轴全局标准化仅拟合名义词0–17；不同用户规则一致。旧第一点Scaler/学生/G/F不更新。

词0–17训练；18–20开发；21–23校准；24–29最终评估。词标签为历史顺序映射，尚未逐条转写核验；本轮为同会话已知身份定位，不是未见身份或跨佩戴实验。

## 模型和训练

编码器为Conv2d32/64/128、GroupNorm、GELU、仅沿频率下采样；频率聚合后保留时间序列，时间均值＋总体标准差拼接256维，Linear256→128、L2归一化。各组完全相同结构、参数量和初始化。临时九分类cosine头scale16，认证时移除。

先共同CE预训练400步，再从相同编码器与分类头检查点继续1000步。每批九人×相同两词×两次独立录制=36；每组使用相同训练批次序列。AdamW lr3e-4/wd1e-3，整体梯度裁剪1；先跑seed42，不称三种子正式验证。

|组别|目标|rho|
|---|---|---|
|E0|CE|0|
|E1|CE＋0.1跨词SupCon|0|
|E2候选|E1＋真实Audio行关系KL|0.03/0.1/0.3|

实际为七个1000步训练分支，而不是仅四个训练分支。E2在正rho候选中选一个用于诊断；同时将E1作为rho=0的合法选择。如果E1优于所有正rho，报告开发选择不使用Audio，不能把正rho诊断冒充部署选择。

## 损失与梯度核查

跨词SupCon温度0.1：正对仅同人异词；异人同词负对logit加log2；同人同词及自比较不入分母。Audio为冻结ReDimNet2-B3的1618条合法训练录制缓存，192维，开发/Cal/最终词没有教师特征使用。

关系监督为温度0.2的行归一化相似度分布KL，比较同一批样本的关系结构，不是逐向量对齐，也不是此前距离/角度RKD的原公式。

身份目标为CE＋0.1CrossSupCon。蒸馏权重由编码器参数上的身份/KD梯度范数计算，EMA=0.9，lambda上限100，目标比例rho。记录实际加权KD/身份梯度比、方向余弦、原始梯度范数与编码器参数变化，均在总梯度裁剪前定义。教师缓存停止梯度。

错配控制不能只整体交换身份名称。每批两个词使用不同的跨身份循环移位，保持词相同与重复序号近似对应，确保同一ACC身份的异词教师来自不同身份。错配采样使用独立随机数，不改变训练批次。检查真实/错误教师关系KL非零。E4教师为同一个CE预训练ACC编码器的冻结输出，仅训练词。

基础检查PASS：梯度进入卷积编码器、参数更新、教师detach、相同关系KL近零、词相关跨身份错配确实改变关系矩阵。

## 模型与融合选择

每100步只在Dev词18–20的固定查询K4原型余弦任务上选择检查点：跨词宏AUC优先，同词AUC次之，再选较早步数。九个训练身份都参与Dev评价。

所有训练分支和rho选择锁定后，冻结编码器提取ACC向量。比较纯学习表示，以及原始720维统计＋alpha×128维表示。alpha=0/.25/.5/1只在Dev跨词RBF AUC上选择，允许0；相同AUC选较小alpha。原始统计不经过新网络替换。

## 最终认证

主后端统一balanced RBF SVC，C10/gamma scale；余弦原型只作为表征诊断。每注册词各身份4条，目标4正、其他八人32负，U5仍作为注册负类；最终过滤U5攻击。

最终六词24–29，30个有向异词组合，折0注册0–3/查询4–7，折1交换。每个同词/跨词比较使用完全相同的查询和标签。每目标每词对/折4本人、28攻击。Cal词21–23固定注册0–3/查询4–7，使用同词/跨词等权分数池，锁定每目标/方法单一阈值，共用于最终两条件和两折。

输出所有八名目标的EER、FAR、FRR、TAR、HTER和AUC；同时报告同人异词、异人同词的相似度间隔，几何诊断仅用实际最终八次重复。词对复用查询，不能当作独立新录制。

## 判读顺序

1. E1对E0：跨词身份监督是否改善。
2. E2对E1：真实Audio是否有额外收益。
3. E2对E3/E4：正确Audio关系是否优于错配和自关系正则。
4. 学习表示与原始统计融合：是否保住统计强项，并提供补充。

不以缩小同词/跨词差距本身判成功，不通过降低同词表现制造改善。最终测试不选择rho、alpha、检查点或用户；单种子先用于定位，后续若确认方法再另行多种子验证。
