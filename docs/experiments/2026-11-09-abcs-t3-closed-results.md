# ABCS T3：四组训练已完成

沿用本日已发布ABCS T3协议，8个已见身份、真实文本全局分组60拟合/15开发/25校准/25查询。每目标25本人、175攻击，BC-only独立RBF认证。channel0作为BC、channel1作为Audio是用户提出、尚未由官方通道说明独立确认的假设。不能据本报告声称物理通道已证实。

模型均为相同ResNet18/192维身份表示、相同18通道辅助头，seed42/200步。无生成器。正确配对辅助目标为拟合数据排名选出的17个谱中心（约158–740Hz）及包络；频带与尺度仅拟合数据确定。Audio辅助回传编码器，校准/查询Audio目标全零。原始数据与逐用户阈值保持私有。

|方法|本人接受率|FAR|HTER|AUC|
|---|---:|---:|---:|---:|
|T0无Audio辅助|93.50%|2.071%|4.286%|0.99517|
|T3正确配对|88.50%|1.500%|6.500%|0.99509|
|T3同人错时|90.00%|1.786%|5.893%|0.99529|
|T3异人同句|91.00%|1.643%|5.321%|0.99474|

八目标宏平均，四组均已实际完成训练和认证。选择checkpoint只用开发身份关系AUC；阈值只用每人25校准句，不按最终结果重选频带、模型或人群。每组共200本人决策、1400攻击决策，攻击录音在多个目标间重复评分，不是1400条独立原始录音。

## 本轮结论

正确配对T3虽使FAR降低约0.57个百分点，本人接受率同时下降5个百分点，HTER比匹配T0升高约2.21个百分点。不能只据FAR宣称Audio有益。正确配对也未超过错时/错人控制，当前没有支持同步Audio辅助带来身份认证增益的证据。

四组AUC均接近0.995，排序差异很小；固定Cal规则下的操作点差异可能涉及分数分布与阈值迁移，但本轮不能把退化全部归因于阈值。只有单seed和一个已探索的闭集子集，也不能据此断言所有Audio辅助方案无效。

此前手工频谱RBF结果是不同前端参考，不能将其与T3直接相减当作教师增益。下一步应优先核实通道语义、保留足够强的原传感器统计基线，再研究可预测且身份相关的辅助目标。跨session与未见身份泛化未由本轮检验。
