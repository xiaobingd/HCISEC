# Mei九人词序审计：数字与VR指令两段排列（2026-10-29）

## 结论与来源

用户本轮确认：每人前100条为英文数字0–9，后200条为20个VR指令。所附词表依次为Start、Pause、Okay、Stop、Menu、Select、Cancel、Confirm、Exit、Help、Next、Back、Off、Grab、Down、Up、Zoom、Record、Play、Reset。

真实Audio频谱的独立诊断强烈支持：前100条为10项一轮重复，后段为20项一轮重复。因此整数组统一用row//10或row%30定义词，均不符合目前证据。用户只确认内容组成；具体每个位置的语义名称/起始偏移尚未逐条人工听录或由文件清单验证，不能把候选数字组ID自动当作已确认文本。

候选分组（索引0起）：

```
row < 100: content_group = row % 10; repeat = row // 10
row >= 100: content_group = 10 + (row - 100) % 20
            repeat = (row - 100) // 20
```

完整300行对应10个数字各10次、20个指令各10次。297/299行用户仍有尾部缺失的用户澄清，但不把这一点当作已核实没有中间缺失或跨用户语义位置完全一致。

## 独立证据（不使用认证成绩选择词序）

- 统一读取配对Audio数组，截至80×80；诊断用时间均值/标准差160维，不修改原数组，不变更认证前端。源哈希保存于results_public.json。
- 前100条与后段分别去说话人平均谱，计算行间距1–60的余弦相关。九人前段均在10的倍数出现强峰，后段均在20的倍数出现强峰。
- 例U1前段lag10为0.648，后段lag20为0.520，而后段lag30为−0.134。U6前段lag10为0.797，后段lag20为0.811，后段lag30为−0.151。

## 对已有实验的影响

10月27日word-major模型真实使用前120条训练、120–149选模、150–209注册、210–239校准、240–296测试。按新候选分组，前120条已经覆盖全部30个内容组；之后各角色均含后20个指令组。因此旧“严格跨词”描述不成立。已有权重和数值结果保留，但应解释为录制样本隔离、内容重复，不能用来证明跨内容。

10月28日PIRA及错误筛除按row//10分组的“认证阶段跨词”同样需要撤回：它们是按伪分组隔离，不等同于真实词语隔离。训练/测试行不重叠的检查仍有效，但不代表内容隔离。筛除实验中未删最终样本与训练折限制仍有效；其结果不能以跨词效果解释。

10月25日统一row%30的内容分析也受此影响。此前“round-major优于word-major”只是两个不完整假设的相对比较，不能把它提升为30词整体轮次的正确标签。

## 修正要求

1. 不复用旧word-major权重作为“严格跨词训练完成”的证据；历史随机150条G/F也不是全流程跨词模型。
2. 重建两段来源清单，保留实际行数、组ID、重复编号和证据来源。跨用户同文本对照前须验证语义/顺序映射，而非按身份结果重排。
3. 如重做严格跨词基线，生成拟合/选模、认证拟合/选模、校准、最终测试均应按真实内容组互斥；所有身份采用同一内容角色表和前端，所有攻击来源保留。
4. 不把本轮内容诊断的较高识别率当成更好的身份认证；本轮没有生成器或认证头新训练。
