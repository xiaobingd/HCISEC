# U1 最初 V1 Diffusion 训练路线的 CPU 适配试跑

2026-11-23。按用户确认，仅运行 U1 个人模型400次更新、seed42，并完成同词及跨词认证。其他9人作为已知攻击身份，包含U10。结果属于单目标、单种子的闭集试跑。

## 版本与适配

训练依据原始 train_ddpm.py 的 V1 路线，双向独立条件 BiometricUNet64，从随机初始化训练，线性beta从1e-4到0.01，共1000噪声步。两方向损失均为噪声MSE＋0.4×SSIM损失，在全部t生效。AdamW lr1e-4、weight_decay默认0.01、梯度裁剪1。每步两方向分别反向传播，降低峰值内存，参数相互独立。

网络文件为现场保存的GroupNorm版本BiometricUNet64，已与本地保留的旧work/model_diff.py哈希核对一致。更早历史归档的网络身份尚未完全追溯。此处版本定位为“现存V1训练入口＋保留旧网络”的任务适配试跑。

训练源SHA256为 621d6bfb68fcfe4b3fc1a60760940583d4ff1d354f73565533bfaaa0180b7bbb。
网络源SHA256为 5001b3e1f27349eb9f573d446b4770d538971e88da355c0a6a5c48805812d4ce。

CPU适配使用40×32输入、batch4、400步（1600次样本呈现，约10轮数据量）、10步确定性DDIM采样。此前80×80/batch8速度测试被系统终止，原因未确认，未产生用于本实验的训练模型。此次40×32完整运行已通过。

## 原始数据和内容隔离

源数据为当前10位完整40词用户的硬件三轴ACC，3200条（每人每词8遍）。ACC前端使用10–300Hz三轴对数功率谱，先对三轴功率求和，以适配原单通道条件网络；原始三轴的频谱/时间/幅度统计保留作独立认证分支。

Audio使用16kHz波形、4096点STFT、hop1024、nfft16384，提取50–7600Hz的对数频谱。前端先缓存80×80，再双线性缩放到40×32。ACC/Audio分别用上游训练集合的全局均值与3倍标准差归一化，裁剪[-1,1]。全局归一化统计使用10人上游训练分区，生成器梯度只使用U1数据。近似同步继承现有数据时间映射，物理延迟尚未独立验证。

U1生成训练20词×8遍＝160条，生成验证6词×8遍＝48条。验证词由固定seed1123从原26个上游词中选出。每100步按固定噪声、t=100/500的两方向去噪MSE＋SSIM验证目标选优，选中第400步，目标0.129435。认证数据不参与生成器更新或选模。

注册及同词词集合为 pause、play、record、reset、four、good bye、one、open device。每词前3遍注册，共24条/人；第7–8遍校准，共16条/人；第4–6遍同词查询，共24条/人。

跨词词集合为 select、seven、six、start、stop、three，每词前4遍查询，共24条/人。这6词与生成训练、生成验证、认证注册词完全区分。本人和所有攻击者使用同样的词集合、重复编号及处理。未删除困难词或攻击来源。

同词和跨词各有U1本人24条、9个攻击者合计216条。RBF注册训练总240条，校准总160条，最终两条件合计480条。源缓存的词ID按词名排序，区别于原始采集W001等提示编号。

## 身份特征和认证

原始统计raw762维，包括三轴频谱均值/标准差、四段时间均值、幅度15维和原始统计27维。

Diffusion特征均只依赖ACC。先从ACC条件及固定噪声生成Audio，再生成循环ACC。t=100/500/900各用两个公共固定噪声模板，提取瓶颈均值/标准差latent1536维；同一带噪输入下有ACC条件与零条件预测之差，得到response252维；循环绝对残差频率均值/标准差和8项统计得到cycle88维。组合bundle1876维。源键guidance在本报告显示为response。V1未使用CFG条件丢弃，零条件差分仅作为诊断特征，尚无无条件分布有效性的保证。

循环信息来自推理时的ACC→Audio→ACC串联；训练损失为上述双向去噪MSE＋SSIM。

各分支StandardScaler仅拟合认证注册集合，再L2归一化；原始与diffusion特征按等权拼接，除以sqrt2。Balanced RBF SVM C=10、默认gamma=scale。阈值由校准集FAR与FRR最接近的点确定，同值优先低FAR；最终查询不参与阈值、权重或超参数选择。各分支全部报告，未用最终指标自动挑选部署分支。

## 验证和判断

训练验证目标分别为100步0.234588、200步0.190349、300步0.151340、400步0.129435。前向去噪目标下降，尚不等同于身份判别改善。

全流程完成220个特征块、880条唯一认证记录；已复核ID覆盖完整、没有重复/遗漏。每块sample_id与源缓存逐条核对；所有特征有限、维度正确；第一批固定噪声采样通过单样本/批量一致性检查。18行指标均有限，HTER均等于(FAR+FRR)/2。原始ACC结果与独立本地对照精确复现。认证缓存真实Audio非零元素为0（880条认证记录），认证阶段未计算真实Audio前向。

预设完整bundle及raw+bundle没有改善：跨词EER分别24.31%、20.60%，raw+bundle的HTER26.16%高于raw18.29%。把所有diffusion信息拼接并不适合此次U1试跑。

响应差分单独使用的跨词EER16.67%、HTER16.44%，分别比raw20.60%、18.29%降低3.94及1.85个百分点；同词EER12.04%高于raw8.56%。这表明本轮更有价值的候选是“ACC条件怎样改变去噪输出”的响应特征。

raw+response同词EER8.33%、跨词EER16.67%，但跨词HTER20.37%高于raw18.29%，对应FRR从29.17%升到33.33%，FAR均为7.41%。其跨词AUC0.9196高于raw0.9097，分数排序与锁定阈值表现存在差异。没有按最终查询重新调阈值。

响应差分属于预设子分支中的探索性发现；本轮只有U1、seed42、400步，尚未验证其他本人或更长预算。当前数据支持继续研究响应特征的跨词价值，完整潜变量/循环大包组合的净收益尚未出现。对照是系统性能比较，原始统计分支没有额外生成训练，不构成等训练预算的编码器因果消融。
