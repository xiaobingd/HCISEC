# 原始 ACC 时序学生与 Audio 辅助初步对照

在原实例使用 CPU 完成，私有教师缓存、模型和音频均留在实例。三个种子42、43、44，每组400步，40条/批次，AdamW lr=.001，身份CE，输出192维。闭集全部10人参与fit；宏平均按U1–U9，U10保留负类与攻击者，结果文件另含U10。

A使用频谱均值、标准差、四段均值、幅度和stats27，经Linear→LayerNorm→GELU→Linear。B使用120通道×28时间帧，经两层Conv1d(64通道、核3)、GroupNorm、GELU，时间均值/标准差池化后与幅度、stats27拼接投影。C与B同结构同初始化同批次，附加41通道预测头，预测40个10–300Hz Audio低频谱及总谱能量包络，按7段时间池化SmoothL1；加已有ECAPA微调教师的样本关系MSE，二者权重各.1。教师缓存只有稀疏选中样本，关系项仅在batch里至少3条有教师目标时启用。全部fit Audio参与动态监督。

Audio低频谱使用4096点STFT、hop1024、nfft4096，40个插值频点并不对应40个独立频率分辨单元。10–300Hz沿用前端候选带宽，尚未由相干性验证。时间池化用于近似同步，物理时延未验证。本轮新增的是动态辅助头；ECAPA保持冻结，尚未完成所提双分支可学习Audio教师主体改造。

使用原fit词训练，8个注册词各3次，24条/人；校准相同8词第7–8次共16条/人；测试词24–29前4次共24条/人。训练/注册/校准/查询索引断言互斥。输入标准化只用fit。ECAPA缓存复用此前合法fit/注册Audio，仅fit子集用于本轮关系蒸馏。查询阶段仅ACC。源压缩NPZ的wave数组整体解压后取fit，查询Audio未计算特征或送入模型。

认证为balanced RBF SVM C=10；阈值按校准FAR与FRR最接近、同值优先低FAR锁定。本轮尚无额外辅助损失消融、辅助任务独立误差诊断和最终独立新词确认。
