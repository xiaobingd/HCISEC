# 冻结 ACC 的多词联合认证、注册模板与有限重录对照

2026-11-23。10位用户全部保留，闭集跨词认证。沿用纯ACC模型，未增加Audio监督，未重训编码器。

## 实验协议

输入为3200条原始硬件ACC的762维统计特征（频谱均值、标准差、四段均值、幅度15维及统计27维）。主编码器762→256→192，冻结此前CE对照的42/43/44三个检查点。其预训练和追加训练仅见26个fit词。RawRBF直接使用原始统计，只有一个确定性评估，不重复计作三个种子。

每人注册词缓存ID20–23，每词6遍，共24条。开发词8、9、18、19、24，查询词25–29；两阶段各词前4遍为初始认证，后4遍仅供同词备用。注册、开发、查询、编码器训练样本和词集合按协议隔离；所有用户用相同挑战词。同一个词的录制索引不同，不将一个波形的切片分到两侧。

本轮为容纳5词认证，把此前查询词24移入开发，查询保留5词。历史已观察这些词的表现，因此这是探索性重新分配，不能作为新增盲测；不可与旧6查询词结果直接归因比较。

固定随机顺序组成1/3/5词挑战，逐条得分取平均。每阶段每个身份分别20/7/4次挑战，每目标对应180/63/36次攻击。3词最后一组循环补用首条录制一次，保留全部20条源记录；该组与首组相关。5词每人仅4次本人挑战，三种子共享同一批查询，不视为新增独立受试者。

后端为RBF-SVM(C10, balanced)、单注册余弦原型、四个注册词原型的Top2相似度平均、LedoitWolf收缩协方差的负Mahalanobis距离。所有配置注册条数固定24；本轮检验模板形式，没有单独估计从12条增至24条的因果收益。RawRBF的StandardScaler只拟合注册，神经模型使用原训练集标准化。

阈值按目标、后端、挑战长度和质量策略分别在开发挑战上选择：FAR≤5%下优先最小FRR，同值优先更低FAR、更高阈值。全部阈值写盘后再计算最终查询指标。开发约束不保证查询FAR≤5%。

质量门限为fit数据三轴log-RMS均值的第5百分位。低能量词可替换为同词另一次真实录制一次；替换后仍低能量则整个挑战拒绝。所有挑战均保留在分母，记录失败与额外采集量。这是低能量代理和离线备用录制模拟，不是经SNR、饱和或掉帧验证的质量评分，也不是真实在线重采实验。

EER/AUC由全部挑战排序计算，质量强制拒绝置于最低分并列；EER为经验ROC中FAR/FRR最接近处的均值。HTER/FAR/FRR使用已锁阈值。报告逐用户平均、再跨种子平均，不以重复词对构造独立样本置信区间。

## 结果判断与下一步

1. 多词联合确实改善了本批查询的身份排序。神经RBF的1/3/5词EER为12.56%/0.24%/0.00%，AUC为0.9367/0.9989/1.0000；原始统计RBF的EER也从21.11%降至6.35%和3.06%。这支持利用不同词提供的互补观测，而不能解释成模型创造了新的身份信息。

2. 排序收益尚未充分转化为锁阈值收益。神经RBF的HTER为14.72%/13.62%/24.17%；3词FAR从4.44%降至0.11%，FRR从25.00%升至27.14%。5词FAR为0但FRR48.33%。开发3/5词FRR仅2.86%/2.50%，查询却为27.14%/48.33%，说明阈值跨词迁移存在明显偏差。这是直接的开发—查询行为差异，尚不能由此唯一分离词难度、采集顺序和阈值估计方差。

3. 低能量门限不是有效的质量策略。神经RBF开启后，1/3/5词HTER变成15.94%/15.82%/28.75%。重录挑战占5.00%/12.86%/17.50%，质量硬拒绝占本人挑战2.00%/5.71%/10.00%。跨词自然低幅度可能仍携带身份信息，不能把能量低直接等同于不可用。当前策略不进入主方案。

4. 多原型与收缩Mahalanobis未超过本轮神经RBF。不能据此认定所有多模板方法无效，但没有证据支持继续增加当前模板复杂度。

5. 下一轮只验证一个方向：固定3词联合和现有编码器，在训练/开发词内部采用留一词组校准，比较词组分数归一化与稳健阈值规则。规则在训练/开发中锁定，再以新留出词或新录制确认，不利用本轮查询阈值反推部署参数。若需要以原始统计作为补充，也只能在开发任务中选融合权重。

0%经验EER不是零风险证明：5词每人只有4次本人及36次攻击，三个种子复用同一数据；3词有一次录制重用。本轮结论是多词提供有价值的排序增益，并定位到校准迁移问题，而非已经达到可部署的低FAR低FRR。
