# 原始 ACC 与 Audio 数据审计及处理方案

10名完整40词用户，分析26个训练词、260组录制、2080个发声片段。分析沿用现有主机时间映射，无最终测试音频。未启动模型训练。

- Audio帧计数时间到主机时间的拟合斜率中位1.08853，残差绝对值P95按录制统计的中位5.61ms、最差175.21ms。需要核对实际采样配置、回调缓冲和时间戳来源。斜率属于主机时间映射，不直接解释为物理采样率。
- IMU批末到主机读数斜率中位约1.000000，录制残差P95的中位1.14ms，最大采样间隔3.00ms。纳入录制未见ACC越量程标记，所纳入Audio片段未见满幅削波。
- 六频带归一化包络按相对时长重采样。正确配对与同人同词异遍错配在各轴频带的平均相关差约−0.0035至+0.0062。短窗边缘、中心填充及起止边界可能影响该诊断。当前结果不足以依据相对时长包络选择可靠的同步监督频带。

## 数据处理方案

1. 统一使用连续IMU与Audio帧编号，核对声明采样率、丢帧、回调间隔和残差突变。记录质量标记。对异常录制回看时间轴，保留ACC身份对照。用训练词比较分段映射与现有回调插值，独立开发词验证。
2. 先计算连续ACC时频谱，窗中心按主机时间映射。使用发声前后真实背景，避免零填充帧参与相关性。按轴保留绝对幅度及背景增强量。
3. 检查Audio高置信F0及各次谐波在ACC中的对应能量。比较正确配对、同人同词异遍、同遍时间平移。配对增益按用户和词聚合。使用开发词验证训练词确定的频带与时延。无物理同步标记时，结果限于相对时序证据。
4. 先确认处理收益，再做等预算纯ACC和Audio监督对照。以跨词锁阈值FAR/FRR/HTER及同人异词与异人同词间隔判断收益。
