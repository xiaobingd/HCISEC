# 44.1kHz时间映射重算

实际完成400组、3200段。全部WAV头与采集metadata reported rate均48000；全部400组帧计数与完整WAV一致。但按帧计数/主机时间推导，有效帧率中位数44096.308Hz。以44100定义音频秒后，主机秒/音频秒斜率中位数1.00008372；原48000则1.08852650。提示采样率标注或采集时间尺度不一致，不应直接把8.85%认作正常设备漂移；尚未由物理共同事件证明真实采样频率。

完整仿射拟合残差不会因单位换算消失：各组残差P95的中位数5.615ms，最差175.211ms。换成44100也不代表物理同步完成。

必须区分两种计算：

- 仅将回调帧时间分母改44100，保留旧分段秒数：分段中心中位移动-566.15ms，最差-1927.16ms；这是单位混用的敏感性结果，不能当校正。
- 将原48000时间基下分段秒数同时乘48000/44100：重算的主机分段边界与旧逐回调插值映射完全一致，最大差0ms。这是保持相同PCM样本边界的自洽重算，已保存私有分段映射。

因此本轮发现的是音频时间尺度/采样率一致性问题，不是已测得566ms物理延迟。历史ACC切片的主机边界不会因为自洽的单位转换自动改变；Audio真实时长、频率轴与重采样却需要进一步核验。不能不加区分地重训所有模型。

所有历史缓存和模型保持不变；新分段映射私有。逐用户见per_user_public.json；仅公开汇总及重算代码，不上传源路径、音频或样本边界。
