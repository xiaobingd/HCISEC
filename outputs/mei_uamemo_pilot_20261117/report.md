# Mei9：UA-MeMo 思路的 Audio–ACC 双头蒸馏试验

日期：2026-11-17。这是监督式跨模态改造试验，不是原作者自监督 DINO 训练的原版复现。没有改动创新点一 V1。

## 调研与实现边界

UA-MeMo 论文发表于2026年，研究自蒸馏/跨架构蒸馏的独立投影头、差异加权与不确定性调节，并在训练后期停止对比项。
来源：[PolyU论文信息](https://research.polyu.edu.hk/en/publications/uncertainty-aware-multi-head-multi-mode-knowledge-distillation-fo/)、[DOI](https://doi.org/10.1109/TASLPRO.2026.3682072)。
本轮未取得原作者代码及完整公式，不能宣称逐式复现或将本轮阴性结果推广为原论文无效。
具体改造：保持原ACC身份编码器及CE头，另设自蒸馏头与Audio蒸馏头；自教师为ACC编码器/自头的EMA，Audio目标来自冻结ReDimNet2-B3训练样本与训练身份原型的余弦logits。
两种模态的logits按同一训练身份顺序排列，因此可以比较，但仍是九位已知身份上的训练任务。
与原文不同：没有ECAPA/ResNet双学生互教、DINO多裁剪或中心化；本轮EMA自蒸馏使用相同ACC视图约束时间稳定性，SupCon停止点固定为100步，不使用动态停止判据。部署使用学生编码器。
不确定性权重采用本实验定义的有界同方差目标：s=2tanh(raw)，辅助目标=sum(exp(-s)L+s)；Audio样本权重由停止梯度的Audio/EMA分布差异决定，截断后均值归一化。它们是本轮选定实现，不是已核验的原论文公式。

## 协议

- 所有九人参与训练、注册、校准和结果统计，全部异人均作为攻击来源。
- 编码器训练：词0–11，每人每词前6条，共648条；标准化仅拟合这些ACC样本。
- 校准：词0–11的第7–8条，共216条；不进入编码器训练。
- 评估：词12–17，每人每词前8条，共432条；K=4注册/4查询，两折互换，同词和跨词共享查询。
- 冻结Audio缓存仅允许训练部分。实现只取648个fit行构建教师目标，不使用任何注册、校准或查询Audio目标。
- 每种子400步CE预热＋各分支400步；各分支同初始编码器、同batch顺序。固定最终检查点，不根据评估结果挑模型。
- 分类头仅用于训练，部署为128维ACC编码器＋balanced RBF SVM(C=10,gamma=scale)。余弦模板作为诊断。
- 阈值仅由训练词的独立校准录制确定，同一阈值用于该用户同词/跨词的两折评估。测试EER用于描述排序，HTER/FAR/FRR使用锁定阈值。
- B1–B4前100步加0.1跨词SupCon，后300步关闭；B0为纯CE。B4用于排除这一额外正则/自蒸馏造成的收益。
- 随机种子：[42, 43, 44]。这是已知用户、未见词的闭集协议，不是未见用户开放集。词12–17已经在历史探索中使用。

## 判断

- B2相对ACC CE：跨词EER变化-0.37个百分点，HTER变化-0.28个百分点（负数为改善）。
- B2相对双头等权：跨词EER变化-0.26个百分点，HTER变化-0.30个百分点（负数为改善）。
- B2相对错误Audio＋不确定性：跨词EER变化+0.58个百分点，HTER变化+0.61个百分点（负数为改善）。
- B2相对仅ACC自蒸馏：跨词EER变化-0.14个百分点，HTER变化-0.13个百分点（负数为改善）。
本轮没有同时通过基线、等权、错误Audio和自蒸馏四个控制的EER/HTER比较，不能据此认定该双头加权改造带来了稳定的Audio独立增益。

本轮把样本可靠性与任务不确定性合并测试，不能单独归因两项各自的贡献。Audio目标压缩为已知训练身份的原型分布，结果仅检验本轮改造。下一步应由这些控制结果决定是否投入原论文公式复现或更细粒度关系目标，不按最终评估分数增加权重搜索。
逐用户bootstrap先跨训练种子平均，再以用户为重采样单位；不把重复词对或训练随机种子视为新的独立参与者。九位已见用户也不足以支持开放集泛化结论。
