# Audio–ACC 谐波对应检验

10人，260组训练词录制与40组独立开发词录制，共2400个片段。最终词Audio保持隔离。连续ACC用96ms窗与16ms步长计算频谱。Audio用归一化自相关筛选周期帧，候选为75–410 Hz内的基频和二次谐波。ACC指标为谐波处能量相对两侧约7.8 Hz邻域的dB优势。基于已有回调插值，片段内Audio按相对位置映射。训练词在三轴、两次谐波和±80ms五档偏移中选两类对照增益较小者最大的设置。开发词固定X轴、二次谐波、0ms附加偏移。

|数据|正确减异遍错配 dB|正确减同遍±160ms平移 dB|
|---|---:|---:|
|训练词|0.103|0.083|
|开发词|0.076|0.088|

开发词有5/10用户同时优于两类对照，平均增益小。当前结果不足以启用逐帧谐波监督。0ms是现有回调映射上的附加偏移，物理时延仍未标定。平移后可能进入词边缘或静音，自相关可能出现倍频错误。窄邻域参考点受96ms窗频率分辨率限制。该试验用于筛查，未检验认证收益。
