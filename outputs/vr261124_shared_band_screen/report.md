# 共同低频结构筛选：可预测性、跨词身份与Audio独立贡献

2026-11-24。冻结第三轮模型，不训练新网络，不读取最终查询Audio或认证测试指标。

## 结果

- 初始两道门：26个频点全部通过正确配对可预测性；其中24个频点70–300Hz同时通过Audio与ACC预测的跨词身份检验。50/60Hz的Audio身份检验未通过多频点校正，不能据此说绝无身份信息。
- 附加归因审计：没有频点在目标用户层面的跨词身份AUC上，经多频点校正后同时稳定超过错遍和异人Audio模型。建议用于下一轮独立身份蒸馏的频点清单为空。
- 70–300Hz只是共享/身份相关候选，不是已验证的额外身份知识；仅排除50/60Hz不足以声称解决已有迁移失败。

## 数据隔离与方法

16训练词1280条用于现有模型和标准化；独立4开发词[8,18,24,30]320条用于本次筛选，10个已见用户。复用第三轮B/C/D三个种子的冻结模型和44.1kHz解释的连续Audio低频目标。最终15个查询内容类Audio从未送入本次筛选，也没有读其认证分数。开发词此前已被查看，因此是探索性选择，不是新的独立确认。

候选50–300Hz，10Hz一个STFT频点，共26个；分析窗100ms、帧移20ms，汇总12个250ms块。频点相关，不是26个独立生理指标。

初始可预测性门：B对真实目标的MSE低于同人同词错遍目标，按用户汇总、枚举1024种符号翻转，对26频点max-T校正p≤0.05；三个种子方向均正；B的真实目标MSE低于C和D模型。没有搜索每条样本的最佳延迟。

初始身份门：每个频点的12维时间结构先平均4条注册录制，另一个词的后4条作为查询原型；遍历4开发词的12个有序跨词对，全部用户使用同一词对。分别测真实Audio和B预测的身份AUC；一致置换查询身份节点，跨所有词对保持同一个身份置换，1000次置换并对26频点做最大统计量校正，AUC>0.5且校正p≤0.05。B预测先平均三个种子；可预测性另要求三个种子方向一致。

追加归因审计明确独立于初始规则：将C/D预测也构造相同跨词原型，计算每位目标的B−C和B−D身份AUC差；按十位目标的差值枚举符号翻转并max-T校正。不把词对、重复或种子当独立受试者。追加审计不能作为独立预注册确认。

## 判断与下一步

当前证据支持ACC可以表达部分低频发声动态，而且这些表示有跨词身份相关性；但C/D也有相当的身份区分能力，不能把上述相关性直接归于正确Audio迁移。正确配对更可预测，不等于它预测出的身份结构更优。

本轮不强行选Top-k、不扩大蒸馏权重、不追加认证测试调参。70–300Hz可用于后续机制核验对照；若要声称身份增益，需要在独立确认数据上比较完整频段/候选频段/无Audio/错配，且同时改善认证指标。目前没有满足独立身份支持的频点，所以不直接启动该蒸馏重训。

物理同步未标定；名义时钟映射、VAD中心、3秒窗口可能包含相邻发声及同词内重叠，均可能贡献局部预测优势。没有声称测量出真实频响/相干性/传递函数，也没有证明ACC独有身份子空间或未见用户泛化。

验证：身份AUC完美分离/全并列/身份错置合成测试通过；26频点、260用户频点汇总和隔离掩码检查通过。公开匿名汇总和代码，不上传波形、embedding、权重、身份映射或逐样本分数。
