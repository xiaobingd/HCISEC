# 261119 原始 IMU 与冻结 ECAPA 前期对照

两种方法分别验证单一信号的身份可分性。原始 IMU 使用 11 人、34 个共有词。Audio 使用 11 人、35 个共有词。

- 原始 IMU 从连续录制截取 1–4、5–8 和 9–12 秒三个窗口，提取三轴频带对数功率和幅度统计。
- Audio 每词取前三个 VAD 片段，使用左声道，截取或补零到 1 秒并重采样到 16 kHz。冻结 VoxCeleb 预训练 ECAPA-TDNN 提取 192 维特征。
- 两项实验均采用五折词划分与逐用户二分类 RBF SVM。标准化和分类器用注册样本拟合，阈值在校准词上确定。同词的注册为前两个窗口或片段，测试为同一连续录制中的第三个。跨词的注册、校准、查询词互不重叠。
- 这两项使用不同词集及取样方式。20261119 的 10 人、40 词完整基线使用另一套固定划分，见[完整基线报告](../vr261119_10x40_baseline_20261119/report.md)。
