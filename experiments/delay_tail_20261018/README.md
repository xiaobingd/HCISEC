# 固定延迟与衰减拖尾诊断

2026-10-18。**允许拖尾后，ACC能量与音频活动的对应有小幅改善；此前要求活动边界逐帧一致过严。但尚不能认定该拖尾来自面部振动，也没有新的身份认证或生成模型成功结果。**

## 协议

沿用同一人的20个训练、4个反复探索验证录制，使用整段共同可用时间，测试录制和28个认证留存录制均未读取。音频活动仍采用训练录制非零能量拟合的统一阈值log10(RMS)=−2.221013。

两种信号都使用20毫秒**后向RMS**，10毫秒采样一步；ACC只做录制级去DC，不做频带滤波，不用250毫秒平滑，避免滤波振铃或不同平滑窗制造拖尾。分别检查XYZ和三轴合成RMS。两端各排除600毫秒，所有候选模型使用同一评估时间范围。该分析衡量低频运动也包含在内的能量包络，并不定位骨传导/面部振动频带。

模型以音频活动构造“即时上升、指数下降”的响应包络，再通过非负斜率及截距预测ACC的log RMS。正延迟代表ACC响应落后于音频。它是用于诊断的**音频参考→ACC能量关联模型**，不是可部署的ACC单输入认证模型，也不是这轮重新训练的音频生成模型。指数释放参数是包络拟合尺度，不是组织力学时间常数。

只在训练录制做20折逐录制留一交叉验证，选择全局延迟和衰减参数；每个录制等权。不为验证录制或每个事件重新找偏移，不改变源时间戳，不使用循环移位。比较同步、仅延迟、仅拖尾、延迟＋拖尾四种模型。初始范围延迟−200至+200毫秒、步长20毫秒，衰减尺度0/30/60/100/160/250/400毫秒。模型的非负斜率限制对应“发声使能量增加”的假设；它不覆盖所有可能的跨模态关系。

预先独立报告三轴合成能量RSS；原始Y轴则是按训练留一表现选出的单轴，不能只报告它而隐去RSS及其他轴。X轴未改善，Z轴非负回归斜率归零，其时延不可辨识。

## 验证结果

指标是ACC log RMS的MSE除以训练集常数均值预测的MSE；先在每个验证录制计算，再对4个录制平均。越小越好，1表示常数基线。它**不是音频恢复误差，也不是身份识别率**。

| 关联规则 | 原始Y轴归一化MSE↓ | 三轴RSS归一化MSE↓ |
| --- | ---: | ---: |
| 严格同步、无拖尾 | 0.9412 | 0.9777 |
| 训练集选择延迟、无拖尾 | 0.9408 | 0.9627 |
| 无固定延迟、允许拖尾 | 0.8856 | 0.9509 |
| 训练集选择延迟＋拖尾 | 0.9048 | 0.9396 |

原始Y轴及RSS的初始训练最优组合均为+200毫秒延迟、250毫秒释放尺度。它相对严格同步在验证上分别降低约3.9%的误差。仅拖尾的Y轴验证数字更好，但没有根据验证把它改选为最终模型。

延迟＋拖尾的Y轴Spearman关联为0.3813，严格同步为0.2682；RSS为0.3420，严格同步为0.2324。这里只是4次录制的描述性平均，相邻帧不独立，没有显著性或身份推断。

## 控制与边界检查

| 延迟＋拖尾模型的控制 | 原始Y轴归一化MSE↓ | 三轴RSS归一化MSE↓ |
| --- | ---: | ---: |
| 当前录制的真实音频参考 | 0.9048 | 0.9396 |
| 只用训练录制的经过时间活动模板，不看验证音频 | 0.9061 | 0.9323 |
| 换另一验证录制的音频参考，沿用同一已拟合规则 | 0.9717 | 0.9946 |

真实配对优于平均错录制参考，说明允许拖尾后存在一定配对线索。但时间模板几乎相同甚至更好，仍不能排除共同朗读流程、头动和设备响应等因素。它尚不足以证明可靠的逐次发声对应或身份特异性。

初始最优延迟碰到+200毫秒搜索边界，因此额外做了**仅训练集**的范围检查：延迟扩大至±500毫秒、释放尺度至800毫秒，没有用新参数重新评估验证或替换上表结果。Y轴最优为+220毫秒/250毫秒，RSS为+280毫秒/250毫秒。训练留一增益距最优不超过0.005的候选中，Y轴延迟80–280毫秒、释放160–400毫秒；RSS延迟200–300毫秒、释放160–250毫秒。这些范围只是接近最优的网格范围，**不是置信区间**。固定链路时延与衰减参数仍可部分互相补偿，不能据此断言存在精确200毫秒的生理延迟。

## 发声边界图

使用同一规则选取边界事件：开始前至少200毫秒安静、之后至少120毫秒活动；结束前至少120毫秒活动、之后至少600毫秒安静；保留前后各600毫秒。最初较短的250毫秒后续安静条件会包含重新发声，故只对事件可视化收紧到600毫秒，不影响上面的全时段拟合和结果。

训练集有14个开始事件（8个录制）、20个结束事件（20个录制）；验证有6个开始事件（3个录制）、4个结束事件（4个录制）。图中蓝线是ACC能量，黑线是音频活动，浅蓝线是各录制。ACC只用训练集共享尺度显示，不做单事件幅度归一化。

训练平均曲线在音频结束后有逐渐下降的趋势，验证曲线波动较大，不能可靠拟合统一的指数衰减。4个结束事件尤其不足以确认组织振动规律。图保存在本地`event_locked.png`（训练选择的Y轴）、`event_locked_rss.png`（独立报告的RSS）和`delay_overlay.png`（固定参数的完整验证录制）。私人信号图、原始数组未公开上传。

## 对后续模型的影响

应当检验训练集确定的有界延迟容忍、非对称释放标签或软活动门控，避免把音频结束后的ACC直接标为无关噪声。模型的时间上下文也应覆盖这一候选范围；不能只把损失标签平移而忽略网络的感受野。保留原始ACC旁路，避免对齐时抹去个体差异。

本轮完成的是延迟假设的信号诊断，**尚未重训延迟感知的神经生成/认证模型**。当前证据支持继续尝试允许拖尾的对齐方法，不能将它直接等同于已经保存身份信息。将来仍需要严格隔离、统一处理的多用户身份验证，并继续保留时间模板和错录制控制。
