# 训练覆盖、小模型与特征循环：未解决个人数据的留出恢复问题

2026-10-18。完成四组×两个种子，共8组最终完整双向循环模型；每组另有内部轮次选择训练。扩大同一批录制中的窗口覆盖、减少模型容量、引入固定统计特征循环，均未改善本批留出音频恢复。不能把训练/验证差距缩小直接称为解决过拟合。

## 数据与处理

仍为同一人的原始OpenVR vAccel。20段训练录制和4段反复探索验证录制，4段测试及28段认证留存录制未读取。旧58个重叠训练窗口的覆盖并集31.2秒；训练录制原始长度共92.277秒。新增40ms步长、800ms窗口的有限裁剪库共1918窗，并集91.92秒，**没有新增独立采集、用户或会话**。

处理及校准完全沿用上一轮：251×81 ACC特征（195条XYZ幅度谱和56条多尺度能量），80×81 Mel；没有逐用户、逐轴、逐窗口增益归一化。重算原58窗口时，ACC和音频相对于旧输入的最大绝对误差均为0。扩展窗口中平均音频活动占比35.4%，旧窗口81.9%，说明覆盖扩展同时改变了活动分布。所有组采用同一规则：每批8个不同录制，75%概率从活动比例至少10%的窗池抽样、25%均匀抽样；不能把它视为仅增加独立样本数量的实验。

## 按整段录制选择停止轮次

20段TRAIN先固定拆为16段拟合、4段内部验证。一个录制的全部窗口只能在同一侧。每组/种子先固定120轮真实配对预热，再训练最多120轮完整循环，每15轮评估内部验证。选择音频MAE/训练均值模板误差与原始ACC循环MAE/模板误差的等权归一化分数最低轮次。然后同种子重新初始化，用全部20段TRAIN预热120轮，再执行已选定的循环轮次。

已有4段外部探索VAL不参与选择。需要明确：为保持可比性，内部拆分仍使用此前20段TRAIN估计的冻结校准，因此是**梯度训练隔离**，不是完全预处理盲验证。一次内部拆分和两个优化种子也不能替代独立会话验证。

## 四组与结果

所有组均含ACC→G音频谱→F ACC及反向循环，F只能读取中间谱，没有原ACC或潜在特征旁路。损失、判别器、优化器、配对预热与TRAIN-only教师策略相同；最终主指标使用干净的F(G)，图中是原G输出。表中为逐验证录制平均后再平均两个种子。

| 设置 | 原58窗训练音频MAE↓ | 留出音频MAE↓ | 留出ACC循环MAE↓ | 音频细节相关↑ | 选择的循环轮数42/43 |
|---|---:|---:|---:|---:|---|
| 固定窗口、完整容量 | 0.1627 | 0.4636 | 0.2197 | 0.0843 | 105 / 105 |
| 扩展裁剪、完整容量 | 0.2487 | 0.5202 | 0.2248 | −0.0575 | 120 / 105 |
| 扩展裁剪、小模型 | 0.2860 | 0.5366 | 0.2299 | 0.0007 | 105 / 105 |
| 小模型＋特征循环 | 0.2946 | 0.5481 | 0.2390 | 0.0217 | 60 / 105 |

小模型是容量组合变更：G由hidden16/2残差块改为hidden8/1块，并移除随层数消失的轴向注意力；F由64宽5块改为32宽3块，不是单独宽度消融。

特征循环保留25%原始ACC谱损失，另外75%约束各频带在5帧/15帧内的均值和标准差；没有可共同坍塌的可训练特征编码器。反向音频循环不变。但固定样例显示循环ACC变得更平滑，这些统计约束仍不足以保证身份细节保留。该版本不采用为已验证的身份前端。

## 能得出的结论

1. 在当前配方下，更多同录制重叠窗口没有代替更多独立录制，覆盖扩大也没有带来留出恢复改善。
2. 小模型提高训练误差、同时恶化留出误差，不能把较小拟合差距称为泛化成功。
3. 这轮固定统计特征循环没有实现“音频对应与ACC细节兼顾”，不能预先将平滑部分解释为传感器噪声。
4. 结果仍不能证明ACC不存在发声或身份信息，亦不能据此断言采集不同步。后续Data0723/mei实验将单独改变独立训练录制数量，而非继续堆叠这20段录制的窗口。
