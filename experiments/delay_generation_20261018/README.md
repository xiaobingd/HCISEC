# 延迟容忍的时序生成与 ACC 保留分支：三种设置、三个种子

2026-10-18。**新方案的生成开始表现出对当前ACC片段的依赖；在接近的生成误差下，重建约束改善了潜在特征的ACC可恢复性。但生成器几乎未利用新增保留分支的全局条件，身份保留仍未验证。**

## 数据和边界

沿用同一个人的原始OpenVR vAccel，20个训练录制、4个反复使用的探索验证录制，58/16个既定音频目标窗口。4个测试录制和28个认证留存录制未读取。没有引入其他用户或扩散样本，没有训练认证头。三个种子不是增加了独立受试者或验证录制。

本轮是**配对ACC→80维Mel谱生成**，不是完整CycleGAN重训，也未通过声码器合成可听波形。新前端对全部三种设置相同：XYZ分别计算STFT幅度及实部/虚部，保留相位与轴间差异；再加入此前固定的56条多频带、多尺度能量。输入为641×129：195幅度谱＋56能量＋390复谱实/虚通道。

原始0.8秒目标不变，ACC上下文为从该目标起点开始的1.28秒，额外包含480毫秒未来上下文；无填充、无样本剔除、不改源时间戳。因此这是离线窗口生成，不是零延迟实时恢复。复谱只用一个训练集共享标量缩放，幅度及能量继续使用既有训练标定，不按用户、录制或样本重新调整增益。三种设置均相同。

注意：能量辅助通道保留了原有零相位带通和50/250毫秒平滑，支持范围比时序卷积更宽。下面的局部对齐范围约束的是**特征索引**，不是对整个原始信号处理链施加严格因果界限，也不能用它测组织的物理传导时间。

## 模型与对照

时序编码器48通道，卷积膨胀率1/2/4、逐帧LayerNorm，不通过跨时间归一化引入隐藏全局上下文。局部注意力只读取ACC，查询取音频时间t对应的ACC t+200毫秒特征，在t+80至300毫秒的ACC邻近特征中软对齐；偏移先验和软活动目标均来自先前**训练集**延迟诊断，不为验证录制寻找最有利偏移。编码器卷积自身还有±70毫秒支持范围。

活动辅助目标是音频活动的200毫秒延迟、250毫秒指数释放；由整段信号计算后再切窗。只用于训练监督。推理时没有麦克风查询、活动标签或真实音频输入。对齐后的时序特征驱动同一个Mel解码器。

| 设置 | 全局ACC候选分支 | ACC重建损失 |
| --- | --- | --- |
| temporal_only | 条件输入置零 | 无 |
| dual_unconstrained | 32通道未门控编码器，均值/标准差通过FiLM参与生成 | 无 |
| dual_preserve | 同上，结构与上一组完全一致 | 有，幅度/能量/复谱分别计均方误差 |

第三组相对第二组隔离了重建损失的作用，避免把新增分支容量直接解释成保留约束收益。全部模型都实例化相同模块，第一组未使用候选分支；其实际可用特征维度更低。

三个种子42/43/44，全部使用120轮×4更新，每次8个不同训练录制、每个录制均匀选窗口；相同种子下批次相同。固定终点，未用验证选择轮次。不做可能破坏相位或引入接缝的循环增强、音高变换、轴置换或样本增益归一化。

共同损失：Mel L1、音频包络L1、频率梯度差、16频带音频描述量回归、训练比例平衡的软活动BCE。保留组额外加入ACC重建损失。**没有把同一个人的不同时间片当作身份负类；没有训练说话人判别或声纹一致性损失。** 全局分支只是身份候选特征分支，不是已验证的身份编码器。

实际训练全部在45582实例RTX3080Ti、PyTorch2.4.1上完成，9个任务均已结束。模型权重保存在服务器`/root/imu_cyclegan_trial_20261016/delay_generation_20261018/results`；本地下载了固定seed42的权重与可视化结果，不按验证分数选择展示种子。

## 三个种子的生成结果

先按4个验证录制等权平均，再报告三个种子的均值±标准差；标准差不是置信区间。

| 设置 | 音频Mel MAE↓ | 双中心化谱相关↑ | 包络相关↑ |
| --- | ---: | ---: | ---: |
| 仅时序 | 0.4100 ± 0.0131 | 0.2613 | 0.2259 |
| 双分支、无重建损失 | 0.4151 ± 0.0208 | 0.2517 | 0.2120 |
| 双分支＋ACC重建 | 0.4098 ± 0.0155 | 0.2686 | 0.2296 |

均值音频模板MAE为**0.4382**。只使用录制经过时间、不读取ACC的固定正弦/余弦时间回归基线为**0.4334**（训练录制等权岭回归，λ=10，频率0.25/0.5/1/2/4/8Hz，规则未按验证选择）。

保留组平均误差比均值模板低约6.5%，比时间回归低约5.5%。但仅时序组与保留组几乎相同，不能说新增分支已经显著提升生成，也不能把本轮相对旧实验的改善归因于延迟单项：复谱、上下文、归一化层、活动平衡和损失均有改变。本轮主要受控比较是新增分支和ACC重建约束。

## 输入依赖检查

| 设置 | 真正晚取400ms ACC后的MAE增加↑ | 换另一录制ACC后的MAE增加↑ |
| --- | ---: | ---: |
| 仅时序 | +0.0851 | +0.0414 |
| 双分支、无重建损失 | +0.0797 | +0.0384 |
| 双分支＋ACC重建 | +0.0843 | +0.0409 |

真正时间偏移控制从**原始录制**重新截取ACC，使用同一冻结标定和原音频目标，不循环拼接、不填充、不寻找最佳偏移；9次训练的录制宏平均均变差。保留组正确输入平均MAE0.4098，晚取400毫秒后约0.4941。早期循环错位数字也保存在结果中，但不作为主要证据。

这比“任意输入都生成类似平均音频”更有条件性证据，仍不是证明每个音节或身份都恢复正确。错录制来自**同一个人**，不是不同用户攻击；且不是所有录制都获得正确配对优势。

| 验证录制 | 生成MAE↓ | 均值模板MAE↓ | 真实+400ms的误差增加 | 换录制的误差增加 |

| recording_02_imu4 | 0.4258 | 0.4435 | +0.1085 | +0.0626 |
| recording_04_imu4 | 0.4023 | 0.4681 | +0.0918 | −0.0086 |
| recording_05_imu4 | 0.4065 | 0.4680 | +0.0918 | +0.0999 |

最后一条仍不如均值模板，第二条换录制反而略好；不能宣称全部录制均奏效。

## ACC信息保留及尚未解决的问题

用相同的**训练集岭回归探针λ=10**，从冻结潜在特征恢复输入特征；不比较未训练的重建头与已训练的重建头。误差除以训练常数均值预测的验证MSE，越低越好。

| 设置 | 幅度谱归一化MSE↓ | 能量归一化MSE↓ | 复谱归一化MSE↓ |
| --- | ---: | ---: | ---: |
| 仅时序，48维潜在特征 | 0.8463 | 0.4362 | 0.3183 |
| 双分支、无重建，80维 | 0.7597 | 0.2279 | 0.1485 |
| 双分支＋重建，80维 | 0.7274 | 0.1248 | 0.1401 |

公平的相同80维比较中，重建约束令能量探针误差下降约**45.2%**，幅度约4.2%，复谱约5.7%。它说明输入信息更容易恢复，**不等于身份信息增加45.2%**；运动、设备和噪声也可能更好地保留下来。

关键负面发现：保留组将全局条件向量置零后，音频MAE平均只变化约**+0.00012**，相比其0.4098误差几乎没有影响。无重建组的对应变化约+0.00348。保留分支虽然能保存ACC特征，生成器却几乎未利用这条通路；不能据此说生成音频使用了它保存的身份信息。单人训练中身份恒定，生成器也可能直接将该人的音色写入参数。

另外将原始中央81帧特征的1282维均值/标准差作为独立旁路，拼接冻结潜在统计量，导出固定1442维**验证检查用**候选表征；第一组未用分支补零。它只保证选定统计量按构造保留，不是原始信号无损或身份有效性证明。这些是反复使用过的验证数据，**不得拿来训练认证头或充当独立认证测试**。认证仍须使用与生成训练隔离的注册及攻击数据。

## 当前结论

可以保留“延迟容忍的时序生成＋独立ACC保留约束”作为后续基线：它兼顾了初步条件生成和输入特征保留。但生成质量仍较平滑、细节有限，收益受种子和录制影响，身份主张尚不成立。

下一项实质问题是让保留分支承担可检验的生成任务，例如预测音频长时谱包络，并与时序细节解耦；随后检查置零/替换该分支是否改变生成的个体相关属性。该思路**尚未训练**，长时谱也混合语句内容与增益，不能预先等同于声纹。最终还需要统一处理的多用户、跨录制独立验证。
