# 音频活动监督下的 ACC 时序学习与跨模态对齐：第一轮对照

2026-10-18。结论：**ACC 信息保留取得了改善，跨录制的音频对应尚未可靠改善；当前没有新的身份认证成功结果。** 恢复质量可以适度让步，但不能用均值模板或错误时间的输入也能生成的纹理代替有效条件恢复。

## 数据与隔离

本轮使用此前确认的同一个人的原始 OpenVR vAccel 录制，不是 Data0723，也不是旧九用户数组。沿用20个训练录制、4个反复使用的探索性验证录制，分别58/16个原有0.8秒窗口。4个测试录制和28个认证留存录制均未读取或训练。重叠窗口和相邻帧不是独立样本；不提供基于独立帧假设的显著性结论。

所有录制执行相同处理：录制级去DC；XYZ分别计算0–500 Hz STFT幅度谱，128点窗、10点步长；不在时域先取三轴模、不按用户单独截频或归一化。加入原始去DC能量及2–10、10–40、40–100、100–200、200–450、450–490 Hz固定带通的50/250毫秒XYZ及合成功率RMS，共56条能量特征。谱用同一训练集标量范围校准，能量用训练集统计量；不对验证录制重新拟合。未来多用户比较也必须共享训练校准参数。

输入为251×81；它包含三轴**幅度谱**，不含STFT复相位，不能称为原始信号无损保留。502维均值/标准差描述量以不经过活动门控的旁路保留，再拼接128维潜在特征统计量，得到630维候选表征。旁路保留的是选定描述量，也可能保留运动和噪声，并非已经证实保留身份。

音频参考保持原始80×81 Mel处理及尺度。活动标签来自先前只在训练录制非零能量帧拟合的双高斯阈值log10(RMS)=−2.221013，不是人工语音标注。无时间戳平移、跨模态拉伸或按验证结果重新配对。麦克风只用于训练监督和参考评估，推理仅输入ACC。

## 四条路径

| 路径 | 训练方式 |
| --- | --- |
| reconstruction | 小型时序卷积编码器，直接恢复音频Mel |
| activity_align | 加活动BCE、带软下限的活动门控、低维音频描述量的同帧InfoNCE对齐；音频损失也按活动加权，是一个组合方案 |
| activity_align_preserve | 在上一组上加未门控潜在特征到ACC输入的重建损失 |
| frozen_preserve_align | 先以随机8帧输入遮挡训练ACC自身重建，再冻结ACC编码器，训练音频/活动/对齐分支 |

编码器不含绝对时间位置嵌入。前三组采用相同seed42、160轮×4次更新、每批8个均匀采样录制；每个录制再随机选一个窗口。训练时ACC、音频及标签共同做时间循环平移，接缝两侧15帧不计损失，无音高、增益或轴置换增强。固定终点评估，未用验证挑最优轮次。最后一组额外80轮ACC预训练，因此不是等计算量比较。前三组本地CPU，最后一组在45582实例RTX3080Ti上运行；条件干预复查统一使用本地CPU，浮点差异小于1e−4。

对齐中的负例是同一人的其他时间片，代表内容差异，**不是身份负类**。这类目标可能更强调语音内容，不能直接替代身份约束。固定单人的数据也无法判断编码器是否丢弃了跨人的身份差异。

## 留出录制结果

音频误差按4个录制等权平均。ACC保留检查对每组冻结表征使用**同一训练集岭回归探针（λ=10）**，恢复输入谱及能量；下表是其验证MSE除以训练均值预测的验证MSE，越低越好。它评估输入特征可恢复性，不是去噪质量、原始波形恢复率或身份认证率。

| 路径 | 音频MAE↓ | ACC谱归一化MSE↓ | ACC能量归一化MSE↓ | 活动AUC↑ |
| --- | ---: | ---: | ---: | ---: |
| 直接恢复 | 0.4644 | 0.8213 | 0.3911 | 未训练活动头，不解释 |
| 活动监督＋对齐 | 0.4870 | 0.8320 | 0.4171 | 0.5518 |
| 再加ACC保留 | 0.4936 | 0.7368 | 0.1265 | 0.5446 |
| ACC预训练后冻结 | 0.4716 | 0.6864 | 0.0662 | 0.4664 |

相同窗口上的训练均值音频模板MAE为**0.4382**，四组均未超过。活动控制：只按录制经过时间预测的AUC为**0.6243**，原始ACC特征的固定L2逻辑回归为**0.6234**，窗口相对位置模板为0.5428。它们都在训练集拟合；本轮窗口范围与上一轮整段活动实验不同，不能直接拿上一轮0.6716或时间基线0.8444横比。

加入ACC保留损失后，潜在特征的能量探针误差相对直接恢复下降约67.6%；预训练冻结组下降约83.1%。这是值得保留的机制线索，**不是身份信息提升83.1%**，且尚未跨随机种子验证。

## 条件性复查

将验证ACC循环错位400毫秒，或替换成另一录制的ACC，再保持真实音频不变。表内是干预误差减正常误差；正数表示正常输入更好。

| 路径 | 错位400ms的MAE增加 | 换其他录制ACC的MAE增加 |
| --- | ---: | ---: |
| 直接恢复 | −0.0008 | −0.0029 |
| 活动监督＋对齐 | +0.0004 | −0.0197 |
| 再加ACC保留 | −0.0057 | −0.0191 |
| ACC预训练后冻结 | −0.0155 | +0.0122 |

正常输入没有一致优势，因此目前不能将生成的谐波或纹理解释为可靠恢复的个人语音。保留组和冻结组也没有通过这个检查。训练中活动占比约81.9%，验证约64.4%；活动分支常输出较高分数，类别不平衡和跨录制分布变化是后续应检验的因素，尚非已证明的唯一原因。

## 对后续路径的判断

保留“原始ACC描述旁路＋ACC自身重建”机制，暂不采用本轮音频对齐模型作为身份认证前端。下一轮优先检验训练集活动类别均衡、扩大同一训练录制中活动/非活动上下文的覆盖，以及将低容量活动分支和ACC保留分支解耦；继续用时间基线、错位输入和错录制控制验收。不能仅增加配对损失或追求更像音频的纹理。

音频与ACC不必具有相同谐波结构。当前结果只说明这轮具体目标和有限训练录制尚未学到可靠跨录制对应，不能据此断言ACC没有语音活动或身份信息。身份结论需要在相同处理和严格隔离的多用户数据上另行验证。
