# 音频域约束与二维ResNet：形态改善，跨录制对应仍差

2026-10-18。**上一版中间谱的音频形态确实很差，不能因为循环相关性高就称为有效音频转换。** 本轮继续保留完整ACC→音频谱→ACC及反向循环，实际完成8次新训练：6次匹配微调、2次二维ResNet配对预热后进入完整循环。结果是异常纹理减少、出现更接近音频谱的轮廓，但真实配对时序尚未恢复，ACC循环细节也有取舍，尚未得到两项目标都满意的模型。

## 数据与隔离

仍为同一个人的原始OpenVR vAccel，20个训练录制、4个反复使用的探索验证录制，58/16个既定0.8秒窗口；4个测试录制和28个认证留存录制均未读取。58个训练窗口存在重叠，按冻结manifest求并集仅覆盖**31.2秒**；它们不是58次独立采集。训练原始录制共同长度约92.277秒，未把所有静音时段增加为新训练样本。

所有实验共享同一251×81 ACC前端：195条XYZ幅度谱＋56条固定多频带能量；目标仍是80×81 Mel，处理规则及训练校准参数相同，无用户或样本单独拉伸、增益归一化、筛选。所有图共享−1到1的显示范围，显示的是原始G输出，不是后处理美化图。

所有最终候选都包含完整双向循环。返回网络F只能读取中间生成谱，不能通过旁路读取原ACC或G潜在特征。没有训练身份认证头，没有身份准确率/FAR/FRR结果，也没有生成可听音频波形。

## 首先确认失配

上一轮固定seed42抗扰动模型中，生成谱频率方向的二阶差分绝对均值约0.6546，真实谱约0.1823，相差约**3.6倍**。相同归一化下，低于−0.8的背景像素比例约4.2%，真实谱约36.7%。这些是描述性失配检查，阈值不是声学活动真值，差分比率也不是越小越好；过低可能意味着过度平滑。

这与贯穿整段的异常纹理一致。旧配置的音频对抗权重0.05、ACC循环权重30，存在容易优先保存输入编码而不匹配音频域的风险；但本轮结果表明，弱音频域约束不是完整解释。

## A：匹配微调，先检查加强约束是否足够

所有路线从相同种子的上一轮`acc_priority` G/F检查点开始，均使用新建的两尺度音频PatchGAN与ACC判别器、40次判别器预热，随后120轮×4更新、每次8个不同训练录制；seed42/43固定。无验证轮次选择。

1. **继续原目标**：ACC循环30、音频循环10、配对音频2、配对ACC2、音频GAN0.05。
2. **音频锚定约束**：ACC/音频循环仍30/10；音频GAN提高到1，配对音频10、配对ACC5；加入频率梯度、活动包络、频带轮廓和判别器特征统计匹配。
3. **锚定＋平滑瓶颈S**：同第二组，但循环为`F(S(G(x)))`，真实谱也先经过S再进入F；S为归一化Mel上的可微3×3平均。图中仍展示未经S处理的原G输出。这样限制依赖细纹理的通路，不是仅把图片画平滑。

三条路线采用相同生成器结构、初始检查点、微调预算和采样次序。第二组是音频锚定组合方案，不能把效果归因于单个新增损失；第三组相对第二组检验S的影响。

## B：结构与训练起点探索

加强约束后仍差，故另外测试不同的生成结构及训练起点：

- G先将251条ACC特征映射为80条频率坐标，再交给项目原`model_drop.GeneratorAccToAudio`二维ResNet生成谱；hidden16、2个残差块、resize-convolution，移除InstanceNorm。原模型文件本身未改，SHA256为`a50c38a48fc9dafe7ac6659d4705b1a90ef95f703724d1713987962f890a4c73`，本地与服务器核验一致。
- G输出端不再直接叠加从ACC到Mel的线性投影，最终输出必须经过二维编码/解码。F继续使用原时序反向网络，因此是原生成器类的适配，不是原`trainb`全流程原样复现。
- 从头训练120轮真实配对预热，随后120轮**完整双向循环**；每轮4更新、每批8录制，两个种子42/43。配对音频20、配对ACC5、音频GAN1、ACC GAN0.05；第二阶段ACC循环权重从10升到20、反向音频循环10。
- 第二阶段用仅训练集的预热G输出作为弱蒸馏参考，权重5；50%训练批次在中间谱上加入S，并对生成谱循环加入0.005噪声。推理不输入真实音频或教师，最终主指标用未额外平滑的`F(G(x))`。

预热阶段单独不是完整循环，不能拿预热图当作最终循环结果。第二阶段才是本文最终候选。B相对A同时改变结构、初始化、训练阶段与预算，是探索组合，不能声称是单组件消融。

## 最终留出录制结果

先对4个验证录制等权平均，再对两个种子取均值。两个种子描述优化变动，不是新增独立受试者，验证集也已多次探索。

| 最终路线 | 原G音频MAE↓ | 音频谱细节相关↑ | ACC循环MAE↓ | ACC循环相关↑ | 频率二阶起伏/真实谱 |
| --- | ---: | ---: | ---: | ---: | ---: |
| A1 继续原目标 | 0.5232 | 0.0049 | 0.1146 | 0.9521 | 3.579 |
| A2 音频锚定 | 0.4887 | 0.0232 | 0.1336 | 0.9315 | 2.464 |
| A3 音频锚定＋S | 0.4872 | 0.0396 | 0.1660 | 0.8756 | 1.757 |
| B 二维ResNet＋预热后完整循环 | 0.4658 | 0.0716 | 0.2176 | 0.7216 | 0.704 |

训练均值音频模板MAE为**0.4382**，训练均值ACC模板MAE为**0.2460**。这些控制按相同训练数据及验证录制重新计算，并非为某个用户特设参数。

音频MAE用于配对转换检查，不是自然度或身份准确率，也不作为循环方法唯一的淘汰依据；允许中间音频恢复有限的研究目标仍然保留。另一方面，频率起伏更接近真实或图像更平滑，也不能代替对应发声时序。

二维ResNet的中间谱比原来的密集编码纹理更接近音频谱的轮廓，但发声位置仍经常不对应、细节较平滑，ACC循环纹理也明显丢失。它没有同时实现可靠对应与原来的循环保留水平，不能因为外观改善就称为任务解决。

在A3中，对中间谱再施加3×3平均，循环误差平均增加约0.0080，较旧循环优先模型的约0.0893敏感性降低；这表明限制细纹理通路确有影响，但对应的ACC重建误差也增加。不能仅凭更耐平滑就宣称身份保留更好。

## 训练集与验证录制之间的差距

对最终检查点额外只读计算，没有再训练、选点或修改模型。两种子录制宏平均音频MAE为：

| 路线 | 训练录制 | 留出录制 |
| --- | ---: | ---: |
| A1 | 0.4452 | 0.5232 |
| A2 | 0.3094 | 0.4887 |
| A3 | 0.2896 | 0.4872 |
| B最终完整循环 | **0.1481** | **0.4658** |

目前最明确的观察是：更强的结构和监督能拟合训练配对，但这种能力没有可靠推广到其他录制。不能简单解释为网络完全没有能力，也不能从这些失败断言ACC不包含发声或身份信息；训练覆盖、跨录制变化、噪声和目标设计的贡献尚未独立确定。本轮没有据此指责源时间戳错误或要求两种模态具有相同F0。

B的真实配对预热阶段验证MAE约0.4783，进入完整循环后约0.4658；因此本轮不是“先很好、加入循环后全部破坏”的简单结论。最终完整循环的配对真实音频→ACC MAE约0.2663，也仍略差于均值ACC模板0.2460。

## 当前判断与下一项可检验问题

上一版中间谱确实不能作为令人满意的音频域转换。本轮改善了异常纹理，形成了形态与循环保留之间的量化取舍，但**还没有同时通过真实配对、音频结构和ACC信息保留的验收**。不将当前候选宣布为认证前端成功。

后续值得检验的方向是：仍保持完整循环结构，将部分约束放到发声活动加权、多尺度稳定特征上，减少强迫所有ACC细纹理（其中可能含噪声）返回的压力。但粗化也可能删除身份线索，不能预先把平滑部分等同于身份；该方向**本轮未训练**，必须用独立多用户注册/攻击数据验证。当前只来自一个人，循环相关性和生成外观都不能推出身份认证效果。
