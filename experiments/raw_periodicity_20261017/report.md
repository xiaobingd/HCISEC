# 原始ACC中的语音周期信息验证，2026-10-17

> **2026-10-17 结论范围修正：本报告仅检验同频基频与线性相干。撤回由此推导的“跨模态转换缺乏输入信息依据/应停止训练”的一般结论。ACC与audio不必具有相同频谱；发声活动对应需另行验证，最新结果见跨模态活动实验。旧数字保留，不能解释为没有发声相关或身份信息。**


**在本轮条件下未检出稳定、突出的同频基频耦合；这只限制该项谐波诊断的解释范围，不能否定跨模态活动关联。**

这不是“ACC没有任何身份信息”的证明，也没有据此认定采集不同步。弱、非线性、低频运动或其他时序信息不在这项基频验证的排除范围内。

## 范围与源文件核验

- 同一人的原始OpenVR vAccel数据，已有20个训练录制和4个反复使用的探索验证录制；没有读取4个测试录制或28个认证保留录制。没有训练模型。
- 24份CSV和对应WAV都与历史源文件SHA256一致；逐点重建缓存ACC的最大差为0，缓存音频与源WAV前缀最大差为0，未发现文件错配或缓存数值变更。
- 实测CSV硬件时间间隔约1.001ms，没有非递增硬件时间；本轮24份文件没有越量程标志。CSV轴值常见步进约0.00238–0.00239m/s²，仅是输出数值分辨率的观测，不能据此推断硬件ADC位数。
- CSV级复核直接在原硬件时间戳上计算非均匀DFT，没有插值、滤波或时间移位，仍未检出稳定基频谱峰。

## 1. 基频附近是否有峰

指标为“参考基频±12Hz平均功率 / 两侧25–60Hz旁带平均功率”的dB值，**是局部谱峰突出度，不是真实信号/噪声已知的SNR**。主分析中心频率60–400Hz；旁带限40–450Hz。参考来自麦克风自动pYIN，未人工标注。

|条件|基频局部突出度，四录制平均|正确配对相对其他录制的优势|
|---|---:|---:|
|原三轴功率和|-0.63dB|+0.10dB|
|原逐轴FIR后功率和|-0.63dB|+0.10dB|
|时间域向量模机制对照|-0.64dB|+0.30dB|
|麦克风正参考|+19.82dB|+22.75dB|
|人工注入麦克风，设定0dB|+4.48dB|+4.78dB|
|人工注入麦克风，设定10dB|+10.51dB|+10.72dB|
|人工注入麦克风，设定20dB|+15.36dB|+16.15dB|

人工注入只检验检测流程：将带限麦克风按同一数学规则混入ACC一轴，设定注入分量相对该轴40–499Hz分量的RMS比。它不是实测恢复结果，也没有进入训练。注入越强，检测越明显，说明本检测在已知信号可见时确实能响应。

各轴分别、三轴合并、固定原FIR前后均未见一致的对应基频峰；训练20录制也未出现系统性的正配对优势。静音/清音区间的局部旁带水平与浊音期间接近。这里的“无稳定谱峰”不排除个别弱片段。

四个验证录制去除重叠窗口重复帧后，分别有122/101/101/128个可用浊音帧，总计452帧；它们不是452个独立实验，统计按4个录制汇总。边界前后70ms排除，避免128ms分析窗的边缘填充。

## 3. ACC与麦克风是否线性相干

256ms无重叠Welch分段，60–400Hz及三个轴平均；每个验证录制17个分段。空对照对每段、每个频率独立随机化麦克风相位，保留各段幅度谱。仅为探索性空对照，不提供帧级显著性p值。

|验证录制|实测平均MSC|随机相位空对照中位数|空对照95分位|
|---|---:|---:|---:|
|recording_02_imu4|0.0487|0.0511|0.0542|
|recording_04_imu4|0.0518|0.0537|0.0573|
|recording_05_imu4|0.0616|0.0640|0.0681|
|recording_08_imu3|0.0543|0.0593|0.0635|

四个录制均没有高于该空对照。与其他录制音频配对、按相同长度计算时也无一致优势。MSC检测线性相干，不是对所有非线性语音关联的检验；整个频带的平均也可能稀释很窄的弱成分。

定义和实现参考：[SciPy coherence官方文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.coherence.html)。

## 4. 时间域取向量模是否改变周期

已在无噪声已知变频正弦上验证：符号三轴的真实基频突出度约+41.26dB，取时间向量模后真实基频降至−5.73dB，折返后的二倍频升至+29.28dB。它证明这一非线性处理可产生倍频/折返风险。

但实测中，无论原基频、半基频还是折返二倍频，都没有出现足够稳定的突出峰。因此**不能把现有失败全部归因于取向量模**。保留三轴是合理的机制控制，但没有在这批数据上自动恢复出清晰语音周期。

补充频率映射分析中心允许至480Hz、旁带至490Hz，与主分析频带不同；各映射的有效帧数明确保存，不能挑出其中最优数字作为独立成功证据。主分析的时间域向量模只复现原非线性操作，所有条件使用同一128ms STFT，未复现完整原模型的Tukey/缩放/80频点输入；不应称为完整trainb重放。

## 结论与下一步

设备输出带宽、噪声底及佩戴耦合测试仍可作为辅助诊断；后续模型也可采用发声活动引导的跨模态时间对齐与特征学习，不应把同频谐波作为唯一前提。两条路径均需统一所有用户的处理规则，并与独立身份验证区分。

当前无声源强度/接触条件控制，不能定位究竟是传导耦合、设备输出特性还是更弱的信号成分所致。也没有用本验证证明时间对齐错误。
